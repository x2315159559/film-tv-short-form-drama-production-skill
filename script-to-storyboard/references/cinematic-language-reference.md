# 镜头语言选择参考

本参考与[影视规则](cinematic-rules.md)共同组成影视板块，为镜头选型和组合提供可扩充的说明，不替代制作规则。条目中的机理解释用于内部选择与推演；对外仍按既有字段、可见性和位置输出边界表达。规则冲突按[全局规则](core-rules.md)的Rule Priority处理。

## 选用说明

首次进入本次摄影设计时先读本节和目录，再按当前场戏的叙事任务、实际行动、人物关系、信息揭示及情绪或形式作用，从下方【按叙事需要选用和落地】查找候选，按需读取具体技法条目。基础概念或相近术语不能可靠区分时，先读相应定义与区别。已经完整读取、内容未变且仍适用的条目可复用，不因镜头或段落换号反复加载整表。

先确定观众当前需要看清、发现或感受到什么，再选择观察范围、视点、构图、固定或运动、合焦与镜头关系。每项均说明定义、表达作用、适用条件、画面落实和区别与边界；作用是可供比较的可能性，不是“一种手段固定等于一种情绪”。不同条目属于景别、叙事视点、摄影运动、承载方式、光学变化或组接等不同维度，可以在真实可执行的画面中组合，不作为互斥模式。

目录与条目不是穷举、技巧白名单、轮换顺序或使用配额；可采用未列出的合理手段。固定摄影与运动摄影均按当前表达选择，不能用换术语证明画面已有变化。组合时写清同时或先后发生的变化、保持不变的关系及实际可见结果，依[影视规则](cinematic-rules.md)【摄影运动的可执行表达】与【整段镜头节奏检查】落实和复核。

采用任何条目均不扩大剧情改写、资产生成、位置输出或工具能力的权限。取景与本镜可见内容按[全局规则](core-rules.md)铁律8-C【取景范围与画面内容匹配】核验；基本视角、人物画面构图位置与主观署名沿既有主定义执行。时长、长镜例外和段落容量只按[分镜交付准入](admission.md)【本次时长选择】；组接和声音按影视规则及连续性主定义，不由参考另设阈值、字段、器材要求或额外审批。

## 按叙事需要选用和落地

按[影视规则](cinematic-rules.md)【按剧情选用摄影、光影与镜内效果】，从采用稿、有效设定及当前实际状态确定这一节拍要让观众看见什么，再比较能在可用时长、实际空间和既有揭示顺序内成立的候选。以下示例中出现的对象、行动及状态均以当前资料已经成立为前提。选用时把实际可见的变化写入对应镜头，逐段、逐镜核对画面、声音和连续性；景别、角度、运镜、构图和组接的机理见本参考相应条目。字段、光影事实与摄影造型、可见性及位置分工分别遵循[输出格式](output-format.md)、[全局规则](core-rules.md)和[位置接续规则](position-continuity.md)。

### 交代整体关系、跟随行动或揭示细节

| 叙事需要 | 适用条件与可见结果 | 镜头提示词写法示例 |
| --- | --- | --- |
| 从局部细节逐步揭示场面规模 | 局部动作是观众进入场面的线索，已有空间、群体和比例关系允许连续揭示。比较直接给大景别与先让观众看清局部、再随拉开和升降看见整体。 | 以斜俯角拍演奏者拨弦的手部特写，匀速拉开至中景，显出演奏者。随后继续拉开，同时平缓升高并加深俯拍角度，让同台乐团和看台上的观众依次入画。接近远景时减速，到远景后稳住，交代舞台与观众席的规模关系。 |
| 逐渐看见原先被遮挡的关系 | 既有遮挡确会因观察方位改变而解除，且可以按当前信息顺序揭示。可比较横移、弧线与镜内人物调度。改变观察方位时，主体的可见侧面或同框对象随运动连续变化。 | 近景，平稳弧移，人物面部的取景尺度保持。原先被人物肩部遮挡的另一人逐渐露出面部。 |
| 持续读清一个移动中的完整动作 | 过程需要看到身体范围及相关行动。可比较固定取景中主体经过画幅与连续跟拍。选择跟拍时，取景可保持主体尺度，周围景物的相对变化交代运动。 | 全景，平视侧向跟拍人物。头部到双脚持续可见，取景尺度保持，沿途柱列随人物前行连续掠过。 |
| 让关键细节成为当前注意点 | 已知细节出现或变化，且此时可以揭示。可比较推近、合焦转换与插入镜头，按是否需要保留同一连续观察过程选择。 | 从手与封套的近景平稳推近至封口特写。手指抬起封边，裂痕完整显露并成为画面关注点。 |
| 让突发行动带动注意转移 | 剧情已有突发行动及相关反应，快速转看能保留这一联系。比较快速摇摄、甩摇及真实切镜，按运动中或落幅后需要读清的信息选择速度。 | 近景，平视。关门声响起时快速横摇，从关门者的面部转向另一人的面部，横摇结束后保持取景，呈现其抬眼反应。 |
| 让摄影与持续高速行动同步 | 主体已经在高速行动，持续跟随有助于读清其运动过程，既有空间和时长允许。依据主体行动选择速度和稳定程度，重点可在持续运动中保持可辨。 | 全景，平视平稳快速侧跟奔跑人物，头部至双脚持续可见，取景尺度保持，人物摆臂和脚步在跟拍中清楚可辨。 |
| 让观众跟住翻转或失衡动作 | 既有动作发生姿态或方向变化，弧移有助于看清主体关系，画幅滚转能表现动作的翻转感。只有两种变化均有表达作用且主体关系仍可辨认时才组合。 | 全景，从接近平视跟住同时腾空的两人，随动作加速弧移，观察角度连续过渡到俯拍，画幅同时短促顺时针滚转至倾斜构图。两人保持同框，动作方向与相互关系可辨。到动作转折处，弧移减速，画幅逆时针回正，保留两人下落的动作。 |

### 用前景与背景控制构图、焦点和信息揭示

每镜先检查实际可见的背景，再判断哪些内容必须看清、哪些可以模糊、哪些要到特定时点才露出。构图由实际可见的框景、遮挡及人物调度落实。焦点按[影视规则](cinematic-rules.md)【进阶】焦点控制表达。下列手法可按同一镜头的叙事需要组合，场景和人物关系按既有规则确定。

| 叙事需要 | 适用手法与选用条件 | 镜头提示词写法示例 |
| --- | --- | --- |
| 引导视线或限制观众暂时能看到的信息 | 采用现有门框等结构做[自然框景](#自然框景)，或依据已成立的遮挡关系延迟揭晓。写挡住了哪个主体的哪一部分及何时露出。 | 门框挡住来人的半张脸。他继续走出门框的遮挡，整张脸显露。 |
| 保留前后层次并集中观看主体 | 取景中已有可用的近处物件时，可让它虚化并保留轮廓。背景虚化适合当下只需辨认主体、环境只需保有大致轮廓的镜头。 | 门框边缘形成柔和的虚影，人物的眼神清晰，身后的厅堂只保留模糊轮廓。 |
| 在同一镜中依次揭示两个对象 | 采用[合焦转换](#合焦转换rack-focus--focus-pull)，依据动作、声音或信息揭示时机决定焦点转移。 | 起初人物的脸清晰，来人仅显出模糊轮廓。脚步停下后，焦点移到来人的脸上。 |
| 让观众同时发现不同距离上的信息 | 采用能让相关对象保持清晰的景深，配合[镜内人物调度与纵深变化](#镜内人物调度与纵深变化)。需要并行看清两处表演或线索时，保留两处的可辨性。 | 说话者与听话者的脸均清晰。说话者继续陈述时，听话者手里的茶杯停在唇边。 |
| 让背景交代实际情境或推进剧情 | 实际可见的背景中，环境变化或人物行为是剧情明确的，或能帮助交代场景状态、空间关系及正在发生的事时，在对应镜头写清主要变化或行为。背景人群可概括共同活动。背景自然静止时按静止呈现。 | 主体继续往门内走。背景的守卫抬手示意，排队的行人随即停下。 |
| 让观众读出景物的远近变化 | 场景和摄影运动支持时，按[横移](#横移truck--lateral-move)的实质选择可辨的视差或遮挡变化。 | 镜头平稳横移，廊柱快速掠过画面，远处主座在画面中移动得更慢。 |

### 用光影造型交代轮廓、表面或状态变化

依据[全局规则](core-rules.md)9-A、9-B和[影视规则](cinematic-rules.md)【进阶】光影世界基底与连续性选用。段级共通光影按主定义输出。锁定照明条件不变时，可按叙事重点设计未限定的摄影造型，镜头内落实随表演、取景或剧情照明变化可见的结果。

| 叙事需要 | 适用条件与可见结果 | 镜头提示词写法示例 |
| --- | --- | --- |
| 让观众读清轮廓或姿态 | 已有照明条件支持轮廓光或剪影，曝光与对比按9-B选择。只需认清姿态时可用剪影。需要辨认表情时，选择能保留面部层次的取景与曝光。 | 暖色轮廓光勾出人物头部和肩线，面部保持在暗部。抬手时，手指轮廓从肩部轮廓中分离。 |
| 让观众发现材质或已有的表面痕迹 | 实际光线、表面及观看角度变化能使可见高光或阴影改变。用这段变化显出已成立的纹理、印痕或边缘。 | 特写，纸张转动时纸面高光减弱，原有压印的边缘逐渐显出。 |
| 让观众看清光照经过的空间层次 | 画面已有足够介质及方向性强光，且其散射实际可见。通过束状亮部、明暗层次或亮区中可见颗粒呈现介质和光线的关系。 | 烟尘中显出一束柔白亮光，细颗粒在亮部中缓慢漂移，亮区边缘逐渐融入周围暗部。 |
| 让照明状态变化成为动作的结果 | 采用稿已有照明变化的触发事件，且光源开关或实际亮暗变化可靠确定。将变化与动作的实际阶段对应。 | 灯亮起时，原先只见轮廓的手和按钮清晰显出。灯光稳定后，手和按钮保持同一亮暗关系。 |

#### 常用影视光影手法

按叙事需要、既有照明与当镜可辨信息选择。输出写实际受光、阴影和变化，可用术语辅助。观众当下必须读清的表情、动作或线索须保持可辨；须延后揭晓的内容按剧情控制到相应时点。下列示例均以照明条件、物件及动作已成立为前提。

| 手法 | 适用条件与表达作用 | 可见结果写法示例 |
| --- | --- | --- |
| 高调布光 | 需要整体明亮、暗部反差较小，并让人物与环境的细节易读。 | 人物与室内陈设都清晰，脸颊和衣褶的阴影浅淡。 |
| 低调布光 | 需要保留较多暗部，通过少数亮区引导注意，或使其余表情和空间细节若隐若现。 | 桌面与信封清晰可见，室内深处沉暗，人物抬眼时眼神仍可辨。 |
| 侧光 | 需要用明暗差突出面部形体、衣褶或表面纹理，已有受光条件支持。 | 面部一侧较亮，另一侧保有阴影层次，衣褶的起伏可辨。 |
| 逆光与轮廓光 | 需要把人物轮廓从背景中分出来，或按揭晓顺序先保留剪影。按表情的可辨需要选轮廓与暗部亮度。 | 肩线和发缘勾出细亮边，人物转头时轮廓清楚。 |
| 硬光与柔光 | 需要边缘清楚的阴影时用较硬的光，想保留柔和的表面过渡时用较柔的光。 | 硬光时窗格投影边缘清晰。柔光时脸颊至下颌的明暗过渡平缓。 |
| 冷暖光对比 | 已有照明支持冷暖差异，且差异有助于区分空间、强调注意点或表现人物经过不同光区。 | 桌边呈暖色，廊下偏冷。人物通过门槛时，衣料上的受光色随之改变。 |
| 顶光与底光 | 需要突出头肩或加深眉眼阴影时，可利用已有自上而下的照明。已有炭盆等低处光源时，可表现下方受光的特征。 | 顶光时头肩较亮，眉骨下形成阴影。底光时下颌受亮，鼻影向上。 |
| 反射补光与负补光 | 需要保留暗侧的细节时，可利用已有表面反光。需要强化明暗反差时，可减少暗侧的环境反光，保持所需细节可辨。 | 反射补光时暗侧脸颊仍有柔和亮度。采用负补光时暗侧阴影加深，嘴角的动作仍能看清。 |
| 图案投影 | 已有窗格、枝叶等结构与光线可形成投影，图案有助于交代空间、分隔画面或控制注视方向。 | 窗格的影子落在桌面，信封的封口处保留在亮处。 |
| 动态光影 | 已有可变光源、遮光物或反光表面，变化能交代画外事件、时间或人物反应。写清变化的触发、落到哪里及如何结束。 | 车经过时，亮斑先掠过墙面，再短暂照清人物的脸，亮斑离开后室内恢复原有亮度。 |
| 人物经过明暗交界 | 实际空间已有可成立的亮区与暗区，人物移动能在合适的时机显出身份、表情或物件。 | 来人在暗处只显出轮廓，走进亮处后面孔才看清。 |

#### 人物面部布光

用于面部确实入画且画面需要读出相应明暗特征的镜头。场景照明、人物朝向和取景须支持这种效果，按这一镜需要识别的表情决定暗部可辨程度。

| 手法 | 适用条件与表达作用 | 可见结果写法示例 |
| --- | --- | --- |
| 伦勃朗光 | 近景需要有清楚的面部明暗塑形，暗侧仍须看得到部分表情。 | 一侧脸受光，另一侧较暗，暗侧眼下留一小片三角形亮区，眼神仍可辨。 |
| 环形布光（Loop Lighting） | 人物近景需要保留自然的面部起伏，同时让表情易读。 | 鼻影斜落在鼻翼旁，与脸颊的暗部隔开，眼神和嘴角清楚。 |
| 蝴蝶光 | 正面近景需要突出面部对称感或颧骨轮廓，且在该视角下能辨认鼻下的影形。 | 两侧脸受光较均匀，鼻下有一片居中的小阴影。 |
| 分割光（Split Lighting） | 需要明显的半明半暗，且当镜允许部分面部细节藏在暗处。 | 面部一半受光，另一半落入阴影，明暗交界近似沿脸部中线。 |

### 用镜内可见效果表现环境、道具或超常作用

从已成立的作用和剧情阶段选择实际可见的效果。写明本镜看得见的触发、承载对象、外观变化及延续或收束状态，必要时在同一段的后续镜头承接实际变化阶段。效果的可见范围与取景按[全局规则](core-rules.md)8-C核验，持续过程的时间和声音按[影视规则](cinematic-rules.md)及[分镜交付准入](admission.md)处理。

| 叙事需要 | 适用条件与可见结果 | 镜头提示词写法示例 |
| --- | --- | --- |
| 让自然作用的起点和反馈看得见 | 采用稿已有动作及环境介质，反馈可随其实际发生。水花、扬尘等可呈现接触、扩散与回落。 | 特写，鞋底接触浅水的一刻，水花从落脚处短促溅起，随后落回水面，涟漪向外扩开。 |
| 让观众读懂道具状态变化 | 剧情已成立道具的发光等变化及相关触发。用实际发光范围、起止和周围可见反馈交代道具状态。 | 特写，随道具启动，其已有刻纹依次亮起，亮度达到稳定状态后保持。 |
| 让已成立的超常作用具有可辨的范围和形态 | 剧情已有能量、气流或其他可见作用，并允许显现其形态。按需要呈现弧线、环形、旋涡、粒子等与主体的关系，按已成立的变化推进。 | 俯拍远景，人物与环形光流同时可见。原有弧形光流连续延伸并闭合成环，发光边缘的颗粒沿环流动。 |
| 让观众看清作用相接后的反馈 | 剧情已有两种作用的相接及可见反应。按实际触发呈现交会处亮暗变化、粒子扩散或周围物件的已成立反应，并保留后续仍存在的变化。 | 中景，两股光流交会时，交会处短暂亮起，细小光点从交会处向外散开，随后逐渐减弱。 |
| 让一次动作带动效果、受光与环境反馈 | 已在发光的物体参与动作，人物受光及环境反馈可由当前接触和材质产生。取景须容纳动作、受光对象与可见反馈。 | 俯拍近景，双手将发光装置缓缓放低，亮光映在手指和水面上。装置底部碰到水面，涟漪从接触处向外扩开，水面光纹随涟漪晃动。双手稳住装置，亮光保持，涟漪逐渐减弱。 |

### 仙侠动作、法术与多人场面的拍摄参考

当施法动作、法术的可见变化或多人之间的关系是本场的信息重点时，按需选用下表。以采用稿及有效设定为准；同一条目可用不同拍法，不因选用示例而新增招式、外观、破坏结果或人物走位。

| 叙事需要 | 适用条件与可见结果 | 镜头提示词写法示例 |
| --- | --- | --- |
| 看清施法手势如何触发变化 | 手势是线索时，选能同时容纳关键手形和触发处的取景，写清哪只手怎样动、变化在哪一刻发生。重点在术法结果时，只交代足以识别的手势，把画面留给结果。 | 手部特写，两掌相对，掌间光环缓缓旋转；右掌翻向上方的瞬间，光环停转。 |
| 看出动作的重量与余势 | 急停或转向时，从本镜可见的支撑、重心变化或衣物随动中选最能说明惯性的细节。身体与随身物不必同时停住，余动的方向和幅度取决于刚才的动作与材质。 | 全景，平视侧拍。人物收步急停，上身略向前倾，随即稳住；宽袖下缘继续向前摆出，随后回落。 |
| 让不同法术有可辨的形态与运动 | 依据该术法已有的形态和作用，选择最能区分它的可见变化，如雷光的分叉、阵纹逐段连通、空间扭曲使背景轮廓偏折。沿用已定外观，粒子、配色和受光按实际效果选用。 | 中景，平视廊柱。空间扭曲处掠过柱身，只有透过这片区域看到的柱缘弯折；扭曲移开，柱缘恢复笔直。 |
| 按大招或交锋的信息重点安排镜头 | 重点是规模时，让观众同时看见法术全貌和熟悉的尺度参照；重点是交锋结果时，让接触处与承受作用的对象可辨。一个取景能读清即可保留；注意点确有转移时再切镜，承接动作已经到达的阶段。 | 表现规模：远景，法相在殿宇后方显现，殿脊仅及法相肩部。表现护罩承压：中景，光流触及护罩，罩面从接触处向内凹陷；光流散去，凹陷处随之回弹。 |
| 看懂多人对峙或群战中的关键关系 | 从已有站位判断观众此刻要辨认哪一组关系，例如谁拦住去路、阵中人与阵外人如何相对。选择能看清这层关系的机位与取景；转看个人反应时，沿用已建立的视线和行动方向。 | 全景，平视斜侧拍，固定镜头。来者和守门人同框，守门人身后的出口清楚可见。来者朝门洞走近，看见挡在门前的守门人，停下脚步。 |

### 在同一生成段组织连续的画面信息

当同一段内确需换观察对象或取景时，按当前事件的动作阶段和揭示顺序比较本参考的【动作匹配】【视线匹配】【插入镜头】【反应镜头】与【声音先入（J-cut）与声音延续（L-cut）】。在各镜正文分别落实实际可见画面及实际发声内容。组接的适用边界、声音和占时依[影视规则](cinematic-rules.md)与[分镜交付准入](admission.md)执行。

| 叙事需要 | 适用条件与可见结果 | 相邻两镜的提示词写法示例 |
| --- | --- | --- |
| 从完整动作聚焦到关键局部 | 同一动作进行中有真实切点，换取景后更易辨认接触或结果。后一镜承接同一动作阶段。 | 前镜“中景，人物伸手推门，门扇刚开始转动。” 后镜“特写，手掌仍贴在门扇上，门扇从已转开的幅度继续打开。” |
| 让观众看见信息被接收时的反应 | 倾听者有获得该信息和作出反应的依据，原说话者的连续语流可承接画面。 | 前镜“中近景，平视许宁的面部。许宁（现场对白）[台词接续]：‘我看到签名了，’” 后镜“近景，平视陈禾的面部，陈禾低眼看向纸面，随即抬眼。许宁（画外对白）[台词接续]：‘不是他的名字。’” |

## 景别：决定本镜让观众看见多少

以下条目用于按当前信息任务比较取景范围，可组合使用，不是穷举、配额或必经顺序。人物部位只是常见尺度参照；制作体系的称呼可能重叠，按实际可见范围落实，不把示意裁切线变成硬阈值。景别切换及“隔一别”统一按[影视规则](cinematic-rules.md)【景别变化与30度法则】，本参考不另设判据。所有条目受主规则的剧情、可见性、资产及位置输出边界约束，手段与情绪不作固定对应。

### 大远景

- **定义**：极大范围的环境、地貌或群体格局构成主体。人物若入画，通常只呈现为很小的尺度参照。
- **作用与选用**：当观众需要一眼看清广域分布、距离感或事件波及的范围时，比较大远景与较小范围的取景。两者的差别在于缩小取景会失去哪一层整体关系。
- **画面落实**：选取采用资料中能显示尺度的已知区域、参照物或群体，交代彼此在同一画面中形成的关系。若还要辨认某人的手势或表情，把该信息留给能看清的取景。
- **区别与边界**：大远景描述取景范围，地面视点也能成立。名称按实际画面使用，不能仅因出场地点辽阔就把局部画面标作大远景。

### 远景

- **定义**：较大范围的环境主导画面；人物若入画，通常占比较小。
- **表达作用**：呈现场面规模、整体行动及人物与环境的关系。
- **适用条件**：当前要读懂整体情境，细小表情或局部动作不是信息重心。
- **画面落实**：写实际可见的既有环境与人物行动；不以微表情承载远景中辨不清的信息。
- **区别与边界**：远景是取景范围，“建立镜头”是叙事功能；远景不只用于场景开头。

### 全景

- **定义**：完整主体进入画面；人物通常从头至足可见，并保留必要环境。
- **表达作用**：让完整行动、多人之间的互动，以及主体与身边环境的关系清楚可读。
- **适用条件**：需要同时看清动作主体与作用对象、数人如何配合或受阻，或脚步、重心及全身姿态如何变化。
- **画面落实**：纳入辨认这组关系所需的主体、身体范围及环境参照，人物画面构图位置按主定义处理。
- **区别与边界**：比远景更突出完整主体；“全”不表示整座场景、所有人物或全部细节都可见。

### 中全景

- **定义**：人物常见取景约为膝部附近以上，保留较多躯干和肢体。
- **表达作用**：兼顾身体动作、姿态与人物间的可见互动。
- **适用条件**：需要较完整的手臂、躯干或膝部动作，脚部细节不承担关键信息。
- **画面落实**：按实际姿态保留动作所需范围，不将未入画脚步写成当前可见内容。
- **区别与边界**：比全景收紧，比中景多保留身体信息；蹲坐或倾身时仍以实际可见部位判断。

### 中景

- **定义**：人物常见取景约为腰部附近以上，兼顾面部与上身动作。
- **表达作用**：使说话、倾听、手势和对象操作能够在同镜形成联系。
- **适用条件**：面部与上身动作同样重要，且所需互动能在这一范围内看清。
- **画面落实**：写实际入画的手势、操作和反应；关键动作超出范围时调整取景或镜头安排。
- **区别与边界**：中景不等于双人镜头，也不因出现对白就自动成为首选。

### 中近景

- **定义**：较中景收紧，常以胸部附近以上为主要范围。
- **表达作用**：加强面部反应，同时保留肩胸变化及有限的身体动作。
- **适用条件**：表情与上身反应需要一起读懂，无需完整手臂或腰部动作。
- **画面落实**：让承担信息的面部、肩胸或入画手势清楚可见，不附带描述未见动作。
- **区别与边界**：与近景的命名边界可能重叠；实际保留了哪些身体范围比标签更能说明差异。

### 近景

- **定义**：人物常以肩部附近以上为主，头面成为主要视觉内容。
- **表达作用**：便于持续观察细微表演，并保留少量颈肩动作语境。
- **适用条件**：关注说话、倾听或反应过程，较大身体动作不是本镜重点。
- **画面落实**：按实际取景写可辨认的表情与颈肩变化。
- **区别与边界**：比中景减少动作范围；靠近面部不自动表示亲密，也不能单靠景别断言人物心理。

### 特写

- **定义**：头面或主体的某一主要局部占据画面，其他信息明显减少。
- **表达作用**：集中呈现反应、辨识特征或具体操作中的关键信息。
- **适用条件**：该局部确需看清，且减少环境信息不会破坏当前理解或揭示顺序。
- **画面落实**：明确取景局部与实际变化，例如面部反应或按键被按下的过程。
- **区别与边界**：相较近景进一步收紧；物件特写不自动是POV，特写也不必依靠背景虚化成立。

### 大特写

- **定义**：只取主体很小的细部，如单眼、嘴部、指尖或物件的局部细节。
- **表达作用**：让容易遗漏的细微变化成为当前注意中心。
- **适用条件**：辨识、操作或反应的意义确实依赖该细节，而非完整面部或动作语境。
- **画面落实**：写清所取细部及其发生的变化，不把局部画面扩写为全脸、全身或隐藏状态。
- **区别与边界**：比特写进一步缩小信息范围；不是将任意特写冠以“极致”或“震撼”的修辞。

## 基本角度：决定怎样看见主体

角度与景别分别判断；这些名称描述观察关系，不授权输出普通镜头摄影机的真实位置、高度或路径。基本拍摄视角、必要可见部位及人物画面构图位置仍按[影视规则](cinematic-rules.md)8-B及【人物画面构图位置】落实，其他位置边界按[全局规则](core-rules.md)铁律8。

### 平视

- **定义**：以接近主体通常视线的水平观察角度呈现；人物常以眼部为参照。
- **表达作用**：便于读清面部、对话与行动，不额外突出明显的上下俯仰关系。
- **适用条件**：当前任务重在表演或信息本身，水平观察能够清楚呈现。
- **画面落实**：写平视及必要可见部位，不追加真实机位高度。
- **区别与边界**：平视不等于正面，也不自动是客观视点；平视同样可以产生强烈情绪。

### 俯拍

- **定义**：以向下的观察角度呈现主体，通常可见更多朝上的表面。
- **表达作用**：帮助读清上表面动作、遮挡差异或较大范围的可见行动。
- **适用条件**：向下观察能有效呈现本镜信息，且所需场景事实已经成立。
- **画面落实**：写俯拍对象及实际可见部位、动作，不用角度标签补造机位依托或场景布局。
- **区别与边界**：俯拍不固定表示弱势；角色低头只是表演动作，不自动使画面成为俯拍。

### 仰拍

- **定义**：以向上的观察角度呈现主体，改变可见表面与轮廓关系。
- **表达作用**：可突出主体的尺度、向上伸展的动作或不同于平视的轮廓。
- **适用条件**：向上观察有助于呈现已成立的行动、体量关系或人物感知。
- **画面落实**：写仰拍对象及本镜可见表面，不因角度新增未成立的上方结构或内容。
- **区别与边界**：仰拍不固定表示强势；角色抬头或朝上看不自动改变摄影角度。

### 顶视（垂直俯拍）

- **定义**：近乎垂直向下观察主体，是俯拍中的特定观察角度。
- **表达作用**：突出平面形态、动作组织或从上表面才能读清的变化。
- **适用条件**：既有内容需要此角度才更易看清，且无需依赖正面表情承载本镜信息。
- **画面落实**：写顶视及实际可见内容；人物可见局部照常定位，道具与场景布局仍守铁律8。
- **区别与边界**：顶视不等于航拍，也不要求远景；角度不能保证所有主体或被遮细节可见。

## 观察视点：决定画面是否归属于角色所见

### 客观观察

- **定义**：画面不严格归属于某个角色所见，由外部观察呈现事件。
- **表达作用**：可在行动、互动和反应之间选择观众当前需要关注的内容。
- **适用条件**：任务不依赖特定角色的主观感知或视野限制，直接呈现对象即可成立。
- **画面落实**：描述实际被摄内容、景别、基本角度与固定或运动方式，不增设视点字段。
- **区别与边界**：客观观察不等于价值中立、全知或固定平视；角色看某物也不使物件镜头自动变成POV。

### 主观视角（POV）

- **定义**：画面明确归属于某个角色所见，呈现其当下的视觉经验。
- **表达作用**：让观众共享有叙事作用的感知、视野限制或视线与动作关系。
- **适用条件**：按8-B【主观镜头的选择与标注】判断，或保留原剧本明确指定的主观摄影。
- **画面落实**：按主定义逐镜署名“{角色基础名}的主观视角”，写清实际所见及其变化。
- **区别与边界**：不自动带入该角色身体、手部或衣饰；不等同FPV飞行或穿越拍法，也不强制移动、晃动。
## 摄影运动与构图动态

以下机理用于选择与内部推演；“画面落实”写入现有字段时，仍守铁律8及【摄影表达与位置隔离】，不把机理改写为普通镜头的摄影机坐标、真实高度、世界路径或物件布局。运动速度与稳定程度按[影视规则](cinematic-rules.md)【摄影运动的可执行表达】分别选择，运动阶段用时按【运镜动势、速度与动静转换】核对。其他时长与连续生成段例外引用各自主定义；这些条目不新增阈值，也不把某种拍法固定绑定某种情绪。

### 固定摄影（Locked-off）

- 定义：机身位置与取景方向保持稳定，不靠摄影机移动或转动重新取景。
- 表达作用：让观众持续比较表演、动作或画面内部的信息变化，也可保留静止本身的作用。
- 适用条件：已有构图能承载本镜任务，注意力主要由被摄内容推进。
- 画面落实：写固定摄影、实际景别和可见变化；人物活动时交代其画面构图变化。
- 区别与边界：固定摄影不等于人物静止；另有变焦或合焦变化时分别说明，不给固定机身添加减速过程。

### 推近（Push-in）

- 定义：摄影机实际接近被摄主体，使其在画幅中通常逐渐增大。
- 表达作用：收束关注、突出细节或逐步改变观众与主体的观看关系。
- 适用条件：接近过程本身有表达作用，且已成立空间支持连续运动。
- 画面落实：写推近的速度、起始与结束景别，以及主体占画比例和可见范围的连续变化。
- 区别与边界：推近会改变观察位置及透视关系；变焦放大只改变取景范围，不能互相替称。

### 拉开（Pull-out）

- 定义：摄影机实际远离被摄主体，使其在画幅中通常逐渐减小。
- 表达作用：扩展观察范围、重估主体与环境的关系，或完成信息揭示与收束。
- 适用条件：更宽的可见范围有叙事价值，扩展内容已有依据。
- 画面落实：写拉开速度、景别的连续变化及新显现的必要内容。
- 区别与边界：拉开不是缩小变焦，也不必然表达疏离；不得借扩展取景补造环境事实。

### 横摇（Pan）

- 定义：摄影机以基本不变的机身位置向左或向右转动取景方向。
- 表达作用：引导横向注意、跟随画内运动，或把已成立内容依次纳入观察。
- 适用条件：信息关系适合用连续转看呈现，且不用换位也能成立。
- 画面落实：写横摇方向、速度、关注对象如何更替，以及最终构图或持续跟随的结果。
- 区别与边界：横摇改变朝向；横移改变摄影机实际位置。单用摇摄跟住主体仍是摇摄，不自动成为移动跟拍。

### 俯仰摇（Tilt）

- 定义：摄影机以基本不变的机身位置向上或向下转动取景方向。
- 表达作用：连续改变纵向关注范围、展示尺度关系或跟随纵向动作。
- 适用条件：关注对象需要沿画幅纵向展开，单靠转向即可完成观察。
- 画面落实：写向上摇或向下摇、速度、可见部位或对象的更替及结束构图。
- 区别与边界：俯仰摇不是机身升降；它是角度变化，也不同于整镜保持不变的俯拍或仰拍。

### 横移（Truck / Lateral move）

- 定义：摄影机实际向侧向移动；需要时可另配摇摄维持关注对象。
- 表达作用：产生可辨的视差、逐步揭示遮挡内容，或沿行动连续观察。
- 适用条件：改变观察位置比原地转向更能完成本镜任务，空间连续可成立。
- 画面落实：写横移速度、主体在画面中的稳定或位移，以及实际可见内容如何变化。
- 区别与边界：横移不是横摇；横移不必跟着人物走，跟随移动主体时才同时具有跟拍功能。

### 跟拍（Tracking / Following）

- 定义：摄影机随移动主体共同移动；前跟由主体前方伴随取景，后跟由其后方伴随，侧跟沿其侧向伴随。
- 表达作用：持续观察行动过程，维持关注关系，并让环境变化交代运动。
- 适用条件：主体行动需要连续承载，采用的跟随方式与取景、轴线一致。
- 画面落实：说明跟拍类型、速度、跟随对象，以及景别和构图的保持或变化；多人入画变化按【摄影运动的可执行表达】处理。
- 区别与边界：前、后、侧跟是机理分类，不要求正文写机身真实站位；跟拍可保持相同景别与构图，不必一律推近或拉远。

### 升降（Pedestal / Crane up-down）

- 定义：摄影机机身实际上升或下降，可与独立的俯仰调整配合。
- 表达作用：改变观察层次、揭示已有遮挡内容，或把局部观察扩展为整体关系。
- 适用条件：机身高度变化具有可见信息作用，空间与动作允许连续完成。
- 画面落实：写上升或下降、速度、视角与可见范围的连续变化；俯仰配合另说明。
- 区别与边界：升降改变机身高度，俯仰摇只改变指向；普通镜头不因此输出真实高度或升降落点。

### 弧线与环绕（Arc / Orbit）

- 定义：摄影机围绕关注主体改变观察方位；弧线为其中一段，完整绕周才是一周环绕。
- 表达作用：连续显现主体不同侧面、改变关系读法，或以环境的相对变化组织注意。
- 适用条件：绕行动机明确，既有空间、遮挡、取景与轴线处理能连续成立。
- 画面落实：说明弧线或绕周、速度，以及取景中的主体和构图如何连续变化。
- 区别与边界：环绕不等于机身滚转，也不必完成整周；不能只写Orbit，更不能借此任意越轴或改固定空间。

### 摄影机滚转（Roll）

- 定义：摄影机绕镜头光轴转动，使画面在观看平面内连续旋转。
- 表达作用：改变画面的方向基准或运动感；具体含义由当前行动、叙事与声画关系决定。
- 适用条件：画面旋转本身有表达任务，且主体辨认与动作连续仍可维持。
- 画面落实：写画面顺时针或逆时针滚转、速度，以及构图从何种倾斜状态变为何种状态。
- 区别与边界：滚转不改变绕主体的观察方位，不是环绕；保持一个倾斜角度属于倾斜构图，不是持续滚转。

### 倾斜构图（Dutch angle / Canted frame）

- 定义：画面水平或垂直基准相对画幅倾斜，并可在镜内保持该状态。
- 表达作用：强调对角线、改变视觉平衡或与当前状态形成呼应，作用不由术语自动决定。
- 适用条件：倾斜有明确构图价值，且不损害观众对必要行动和关系的理解。
- 画面落实：说明画幅向哪一侧倾斜、是否保持，以及人物实际画面位置；需要恢复端正时写清变化。
- 区别与边界：倾斜构图是画面状态，滚转是造成状态变化的运动；画幅倾斜与俯仰等基本拍摄视角分别判断。

### 甩摇（Whip pan）

- 定义：迅速转动取景方向，使画面在转向过程中出现短暂、显著的运动模糊。
- 表达作用：快速转移关注、承接突发动作，或在有依据时组织转场。
- 适用条件：关注转换确需该速度，转向后仍有可辨的对象或构图落点。
- 画面落实：说明甩摇方向、转向前后实际可见内容，以及模糊如何出现、如何恢复清晰。
- 区别与边界：甩摇不是快速横移或快速变焦；是否切镜按真实剪辑判断，一镜到底不得借甩摇暗设切换。

### 复合运动（Compound move）

- 定义：两种或以上摄影变化同时配合，或在同镜中有次序地衔接，如横移配摇摄、升降配俯仰。
- 表达作用：在连续观察中兼顾主体动作、信息揭示和构图调整。
- 适用条件：单一运动不足以完成任务，组合后仍有清楚、可执行的画面过程。
- 画面落实：写清哪些变化同时发生、哪些先后发生，各自速度及最终可见结果。
- 区别与边界：不是堆叠运镜名称；内部校验组合后的空间和投影，正文仍守位置输出边界，不自动获得长镜例外。

## 摄影承载与特殊摄影

### 手持摄影（Handheld）

- 定义：摄影机由操作者身体支承和操控，可有受控的细微浮动，也可按需要增加运动幅度。
- 表达作用：形成贴近行动、即时观察或自由响应的观看质感。
- 适用条件：响应表演与行动比绝对稳定更有价值，浮动程度不妨碍必要信息辨认。
- 画面落实：说明手持浮动的强弱、节奏，以及固定观察、跟拍或转看的实际方式。
- 区别与边界：手持不等于剧烈晃动；它是承载方式，可与推拉、摇移、跟拍组合，也不自动成为主观镜头。

### 稳定跟随（Stabilized follow）

- 定义：通过稳定承载抑制非预期抖动，使摄影机随主体移动时保持受控、连续的画面。
- 表达作用：让行动易于阅读，保持连续观看，同时减少操作者步伐对构图的干扰。
- 适用条件：主体持续行动且需要平稳伴随，已有空间支持该连续观察。
- 画面落实：写平稳跟随及选定速度、跟随对象，以及景别和取景的保持或变化；采用速度变化时按【摄影运动的可执行表达】落实变化节点。
- 区别与边界：稳定跟随是跟拍的承载与稳定特性，可与快速或缓慢运动组合，不等于静止，也不保证景别不变；不要求增加器材字段。

### 航拍（Aerial cinematography）

- 定义：由飞行平台承载摄影机形成空中观察，可稳定停留，也可连续移动。
- 表达作用：呈现已有空间的尺度、关系或行动全貌，也可完成地面观察难以实现的视角变化。
- 适用条件：空中观察提供必要信息，实际呈现范围和空间资料足以支持。
- 画面落实：说明航拍、基本视角、移动或稳定状态、速度及可见范围如何变化。
- 区别与边界：航拍不等于只向下俯拍，也不必高速飞行；普通镜头仍不输出飞行高度、世界路线或补造完整布局。
- **选用示例**：剧情先要交代城门与进城队伍的规模，再让观众找到守将。可用航拍远景起幅，先让门前队列清楚可辨，再快速推进，接近全景取景时减速，落在守将抬手放行的全景后稳住，让其放行手势清楚可辨。起幅观察、推进、减速及落幅观察分别按实际占时核对，合计满足镜头上限。若更广的环境关系本身也要交代且资料足以支持，可从大远景起幅。若连续飞近来不及让观众读清两端，可在守将示意的节拍切入，分别安排两个镜头。

### FPV穿越机摄影（FPV drone）

- 定义：以飞手第一视角操控的无人机承载摄影机，能形成灵活、连续的飞行观察。
- 表达作用：以飞行动势连接已有内容、伴随高速行动，或表现有依据的连续穿行体验。
- 适用条件：飞行与穿行确有表达价值，空间连接和通行条件已成立。
- 画面落实：说明飞行动势、速度、取景变化和可见内容更替；具体摄影路径输出仍按既有主定义。
- 区别与边界：FPV是摄影实现方式，POV是叙事视点，二者可交叉；FPV不自动属于某角色，也不强制高速、翻滚或身体入画。

### 机身绑定摄影（Body-mounted / Snorricam）

- 定义：摄影机与演员身体支架绑定，共随身体运动；拍向演员时可使其在画幅中相对稳定。
- 表达作用：对比身体与环境的不同运动感，持续贴附行动或突出身体经验。
- 适用条件：该相对运动关系有表达任务，已有动作与取景允许实现。
- 画面落实：写清哪些实际可见部位在画幅中相对稳定，环境画面怎样随行动变化及浮动程度。
- 区别与边界：机身绑定不同于操作者手持或自由跟拍；拍向演员不等于演员眼中所见，不因绑定而补手脚、支架或隐藏身体入画。

## 变焦与焦点控制

### 变焦（Zoom）

- 定义：通过镜头变焦改变取景范围与成像大小，本身不要求摄影机实际接近或远离主体。
- 表达作用：扩大或收束可见范围，突出细节，或让取景变化本身成为可见表达。
- 适用条件：需要改变画幅内容或占比，而该效果适合由变焦完成。
- 画面落实：写放大或缩小变焦、速度、起止景别或取景范围，以及对象占画比例变化。
- 区别与边界：变焦不是推拉；仅变焦不产生移动观察位置所造成的透视变化，也不是合焦转换。

### 快速变焦（Snap / Crash zoom）

- 定义：迅速完成明显的变焦，使取景范围或对象大小在连续画面中快速改变。
- 表达作用：突然强调、迅速重定注意或形成节奏变化，可依情境服务多种语气。
- 适用条件：快速取景变化有明确作用，主体和信息在变化后仍能清楚辨认。
- 画面落实：写快速放大或缩小、关注对象、变化前后景别及变焦结束后的实际画面。
- 区别与边界：它仍是变焦，不是快速推近、甩摇或切镜；不靠术语自动附加惊吓或喜剧效果。

### 希区柯克变焦（Dolly zoom）

- 定义：摄影机实际推近或拉开，同时配合相反方向的变焦，使主体大小基本保持，背景透视关系明显变化。
- 表达作用：把观看关系的异常变化显现出来，可用于认知、状态或关系的转折。
- 适用条件：有可辨的背景变化，主体大小维持与推拉、变焦的配合能连续成立。
- 画面落实：写推近配缩小变焦或拉开配放大变焦、主体占画比例基本稳定，以及背景视觉关系怎样变化。
- 区别与边界：单纯推拉、变焦或把主体放大缩小都不是此效果；不是合焦技巧；按现有字段描述实际画面效果。

### 合焦转换（Rack focus / Focus pull）

- 定义：在同一连续镜头中把清晰关注从一个合焦对象转向另一个，产生可见的清晰程度变化。
- 表达作用：不切镜地重分注意、揭示信息或显现已成立对象之间的关注关系。
- 适用条件：转换对象实际入画，清晰变化可辨，且转换时机与信息揭示一致。
- 画面落实：只写先合焦谁、何时或随何动作转向谁，以及转换的快慢与可见清晰变化。
- 区别与边界：不是变焦或自动推近；不以人物视线移动直接代替摄影合焦，也不借合焦补写对象位置或主合焦平面。

### 焦点跟踪（Focus tracking）

- 定义：随主体或摄影状态变化持续调整合焦，使指定对象保持所需清晰程度。
- 表达作用：维持观众对持续行动或关键表演的辨认与关注。
- 适用条件：主体运动或摄影变化会影响合焦，且需要持续保留同一关注对象。
- 画面落实：说明持续跟踪的合焦对象，以及有依据的失焦、重获清晰等实际变化；无需指定自动或手动实现。
- 区别与边界：焦点跟踪不等于摄影机跟拍，也不要求对象居中或景别不变；改向另一对象时按实际合焦转换说明。
## 构图与镜内组织

### 单人、双人与多人构图
- **定义**：单人主要呈现一位人物；双人将两人同框；多人组织三人及以上或人群的同框关系。
- **表达作用**：单人聚焦个体变化，双人保留互动，多人呈现群体关系及注意力转移。
- **适用条件**：依据当前关注对象、互动是否需要同时看见，以及必要信息能否清楚辨认来选择。
- **画面落实**：选择能承载互动的景别，写各独立人物实际可见部分的画幅位置；背景人群说明所占范围。
- **区别与边界**：人数构图不限定景别，也不要求轮换使用；肩背等局部仍按实际入画登记，不能因强调一人而漏掉可见他人。

### 对称与不对称构图
- **定义**：对称以画面两侧或上下的近似对应形成组织；不对称用不同视觉分量形成平衡或有意偏重。
- **表达作用**：可呈现秩序、稳定、仪式感，或突出侧重、关系变化与张力，含义取决于内容。
- **适用条件**：既有主体与环境能够支持所需组织，且能让观众更清楚地理解当前节拍。
- **画面落实**：交代人物可见部分的画幅区位与取景形成的对应、偏重或变化，不只写构图名称。
- **区别与边界**：不对称仍可平衡，对称也可显得压迫；不把形式固定对应某种情绪，不为对齐画面改动资产布局。

### 负空间与留白
- **定义**：用主体周围较少承载主要信息的画面区域，与主体形成疏密、大小及视觉分量关系。
- **表达作用**：可突出孤立、等待、舒展、方向期待或失衡感，也可使主体更易辨认。
- **适用条件**：已有场景取景能够提供有效留空，且当前情绪、视线或动作确实需要这种关系。
- **画面落实**：写人物在画幅中的位置、占幅大小及留白形成的观看效果，保持必要可见信息。
- **区别与边界**：留白不必纯色或全无纹理，也不设面积比例；不能为留白无依据移除场景资产，或把空处当作新增人物事件的许可。

### 自然框景
- **定义**：借已存在的门窗、拱口等可见形状，在单一物理画面中形成围合或局部围合的取景效果。
- **表达作用**：引导注意、强化分隔或联系，使人物与环境的关系更清楚。
- **适用条件**：已采用空间确有可用结构，当前可见范围与摄影设计能自然形成框景。
- **画面落实**：描述既有结构形成的自然框景效果及人物可见部分的画幅位置；形状依据有效资料，不外写框体区位来补布局。
- **区别与边界**：自然门窗框景不等于人工画中画；不新添或移动框体，也不借框景输出普通镜头的机位关系或人物真实站位。

### 镜内人物调度与纵深变化
- **定义**：以人物姿态、视线、走位等连续变化重组镜内关系；人物纵深运动还可改变其投影尺度。
- **表达作用**：在连续表演中转移注意、呈现关系进退或完成信息揭示，减少无表达作用的切镜。
- **适用条件**：当前表演与有效空间支持连续变化，且无需改动事件、行为目的或揭示顺序。
- **画面落实**：写清可见动作及人物画幅位置、尺度的起始、变化和结果；实际纵深与可行性内部推演，景别变化按其主定义表达。
- **区别与边界**：普通姿态与走位可按铁律3落实；不能补新事件、改固定资产布局，或把纵深设计扩成对外真实路径说明。

## 镜头关系与连续组接

### 过肩镜头（OTS）
- **定义**：肩部所属人物的肩部或肩背局部实际入画，同时呈现另一被摄主体的构图关系。
- **表达作用**：保留互动联系，使观众同时感知观察、回应或对峙关系。
- **适用条件**：肩部局部对当前关系表达有用，轴线、视线及所需可见范围能够成立。
- **画面落实**：按8-A明确肩部所属角色与被摄主体，并写实际入画人物可见部分的画幅位置及主体变化。
- **区别与边界**：过肩是单镜构图，正反打是跨镜组织；肩部未入画不套用此表达，被摄主体也可为已成立的物件。

### 正反打
- **定义**：在相互关联的观看、交流或行动方向之间切换镜头，组织人物及其所关注对象的关系。
- **表达作用**：使互动、回应及双方信息差清楚，也可通过不同承载方式突出关系变化。
- **适用条件**：关注对象确需切换，前后视线、轴线及动作接续能够成立。
- **画面落实**：分别落实每镜所看对象、可见表现和切点；可用单人、过肩或其他合适构图承载。
- **区别与边界**：不要求每句台词切一镜或机械轮换说话者；不等于双方必须同景别，也不自动成为任何人的主观镜头。

### 反应镜头
- **定义**：以人物对已发生或正在发生的信息、行动、声音所表现出的可见回应为主要任务。
- **表达作用**：让观众感知信息如何作用于人物，保留倾听、判断及情绪变化的过程。
- **适用条件**：回应有剧情或普通表演依据，对当前节拍有用，且人物此时能够获得相应信息。
- **画面落实**：呈现具体可见反应及其进程；需要时承接原说话者的画外对白，按实际发声片段自然接续。
- **区别与边界**：反应不必夸张、沉默或只拍脸；不补人物尚不知情的回应，不为换画面重复台词，也不要求反应者对口型。

### 插入镜头
- **定义**：在当前场面中突出一个已成立细节，使观众清楚看见物件、文字、局部动作或状态。
- **表达作用**：强调线索、操作关系或关键变化，补足较大范围画面不易看清的信息。
- **适用条件**：细节确实存在、当前允许揭示，且独立强调比继续原画面更有表达作用。
- **画面落实**：按所需辨认范围取景，交代实际可见细节、变化及必要关系；原声音可依既定语流跨镜。
- **区别与边界**：插入描述镜头功能，不是固定景别；不把台词提及直接拍成事实，不为凑镜增加无关物件或提前露出线索。

### 动作匹配
- **定义**：以同一连续动作在切点前后的对应阶段连接不同取景，使动作被感知为持续进行。
- **表达作用**：在更换关注范围时保留行动的连贯性，并让必要过程或结果看得更清楚。
- **适用条件**：确有连续动作及换镜理由，前后参与主体、动作阶段、方向和必要关系能够衔接。
- **画面落实**：前镜写至实际切点，后镜从接续阶段推进，保留理解动作所需的可见变化，不重演已完成部分。
- **区别与边界**：匹配的是同一动作的连续进程，不是两个不同动作看起来相像；运动中不必逢动作就切，也不能用匹配名义跳过必要过程。

### 视线匹配
- **定义**：通过观看人物与其所看对象的镜头关系，使观众理解视线指向及观看内容。
- **表达作用**：引导发现、建立关注关系，并清楚组织观察与回应。
- **适用条件**：人物此时确能看见相应对象，且呈现顺序符合既有信息揭示。
- **画面落实**：交代可见视线变化与所看对象的实际内容，内部校验视线、轴线和空间一致性。
- **区别与边界**：所见镜不自动等于主观镜头；主观署名按8-B，不使观察者身体入画，也不外写隐藏声源或观察者的真实位置。

### 图形或构图匹配
- **定义**：以相邻画面在形状、轮廓、色彩或构图关系上的可辨相似形成连接。
- **表达作用**：联系两个已有画面，形成联想、对照或视觉上的顺畅承接。
- **适用条件**：前后内容均有采用稿依据，相似性能够服务已成立的叙事关系。
- **画面落实**：明确前后各自的实际画面及承接特征；涉及人物的匹配写可见部分在画幅中的区位与形态变化。
- **区别与边界**：视觉相似不表示同一地点、同一物件或时间连续；不靠物件变形、偷换资产身份或重排揭示顺序制造匹配。

## 切换、转场与声画组合

### 硬切与有意跳切
- **定义**：硬切让一个画面直接替换另一个；有意跳切使同主体、相近取景中的时间或动作变化呈现出可感的断裂。
- **表达作用**：硬切可清楚推进或转移注意；有意跳切可强调断续、压缩或突变感。
- **适用条件**：直接切用于前后关系清楚之处；有意跳切仅在既有规则允许的明确表达中选择。
- **画面落实**：写实际切点及前后内容；选择有意跳切时，明确呈现何种已成立变化及其断续效果，不只附术语。
- **区别与边界**：硬切可以保持完全连续；不能把无动机的近似构图切换事后命名为跳切，也不借此豁免现行切镜、动作及台词要求。

### 平行与交叉组接
- **定义**：都以画面交替组织多条行动线；此处以平行侧重并列对照，交叉侧重同时推进及相互牵动。
- **表达作用**：可比较处境、建立信息差，或呈现同时发生的行动如何接近、影响彼此。
- **适用条件**：采用稿已有相应行动线及允许的呈现次序，切换能让关系更清楚。
- **画面落实**：各镜写对应行动线的实际场景、行动阶段和声音，内部分别续接状态，切点服务当前对照或牵动关系。
- **区别与边界**：术语用法存在重叠；是否同时、相遇或有因果由采用稿决定，不能由名称推定，也不为交替而新造另一条行动线。

### 叠化与遮挡转场
- **定义**：叠化使前画面渐隐、后画面渐显并短暂交叠；遮挡转场借可见覆盖与重新显露衔接画面。
- **表达作用**：叠化可柔化更替或联系时空；遮挡可利用已有可见变化完成注意与画面的交接。
- **适用条件**：用于视频提示词的转场须符合[影视规则](cinematic-rules.md)【视频生成转场边界】。常规叠化由已有画面经剪辑完成。采用遮挡时，前后场景及具体遮挡过程须有可成立的依据，且该画内过程需要生成。
- **画面落实**：写实际遮挡怎样形成、以什么画面收束，以及后一镜怎样显露。跨段时各段独立交代可生成的部分。
- **区别与边界**：短暂交叠不同于遮挡覆盖；不默认物体变形或空间穿越，不在不中断长镜的容量接缝借机换镜，也不转交人工后期。

### 声音先入（J-cut）与声音延续（L-cut）
- **定义**：J-cut让后续画面相关声音先于画面切换进入；L-cut让原画面的声音在画面切换后继续。
- **表达作用**：先声可引导期待，留声可维持语流或情绪，使观看对象切换仍保持声音联系。
- **适用条件**：已有对白或音效适合这样承载，且不改变事实、揭示顺序及自然发声关系。
- **画面落实**：分别落实画面切点与实际声音起止，每镜只写本镜发声片段、主体和方式，连续语流按实际阶段衔接。
- **区别与边界**：区别在声音先于新画面还是延续到新画面；画外声不使身体入画，也不表示双方必须重叠说话、断句或重复起句。

## 画面时间与声画重音：定格、变速及声音与画面变化的同步

### 画面定格（Freeze frame）

- **定义与选用**：把选定的一帧影像保持一段成片时间。用于让观众看清某一结果或感受一个停顿，选帧时应让这一刻的重要信息已在画面里成立。
- **画面落实**：写清定在哪一帧、保持多久。如本镜还要恢复运动，写明何时恢复。按实际安排保留或收束声音，画面定格不自动停止声轨。
- **区别与边界**：机位固定时画内动作可继续，人物停住时周围仍可变化。只有整帧影像被保持才称定格。

### 影像变速与渐变速（Speed change / Speed ramp）

- **定义与选用**：改变一段动作在画面中的播放速度。速度连续过渡时可采用渐变速，以突出关键动作阶段或改变观众感受到的节奏。
- **画面落实**：指明哪段可见动作以什么速度开始、从哪一刻加快或放缓，以及落在什么动作阶段。需要复常时写明落点。自然对白的语速与必要动作阶段按采用稿和既有估时规则处理。
- **区别与边界**：摄影机加速跟随、人物自行加快脚步和影像播放加速是三种不同的变化。只描述实际选用的一种或能同时成立的组合，不因段落将满而加速。

### 声画同步重音（视听同步点）

- **定义与选用**：将可辨认的声音落点与动作、揭示、摄影运动的起止或剪辑切点对齐，使结果、转折或节奏得到强调。可用已有动作声、对白的语气重音或已指定音乐的节拍，不为制造同步点自行添加配乐。
- **画面落实**：写清是哪一声、与哪一画面变化同时发生。声音出处和真实占时按现有声音字段与计时规则处理。
- **组合示例**：剧情已交代闸门正在关闭。由即将对合的锁扣近景快速后拉，逐渐露出整扇闸门。在锁舌落下的金属重响处拉至全景，定格在闸门完全闭合的一帧，保持半秒。若要观众继续看见门扇余震，则在同一声响处结束后拉、保持固定取景，让余震继续。
