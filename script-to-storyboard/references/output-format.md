## 分镜正文与交付格式

**【输出总结构铁律】**：按[分镜交付准入](admission.md)【本次时长选择】取得L，核验采用剧本和必要资料，完成本批N段的内部A/B/C、实际镜头正文和整数总时长，再按[全局规则](core-rules.md)【实体实际出场计次】统计各版。视频提示词、资产及应随附的剧本分别按[可编辑 HTML 交付](../../short-drama-storyboard/references/delivery.md#可编辑-html-交付)交付。文件标明容量版归属，版本名在投喂正文外。资产登记采用与实际交付分别记录。本模块只制作分镜及实际需要的人物位置图提示词，使用对应模块的资产和剧本成稿，制作记录及书签只在内部使用。

**【内外分工】**：镜头按core-rules.md铁律1、8-C及Workflow §3写实际可见内容、必要摄影、声音与估时；人物锁定与位置图另按[人物跨段位置接续](position-continuity.md)的接续条件、有效在场记录及实际镜号执行；文字只记录真实位置与对应镜头的画面构图，姿态和动作仍在镜头表达。当前画面必需且已确定的佩戴、持有、接触、遮挡、放置及变化关系须写清；必要衣物遮挡不因物体全遮而省略，也不使被遮物本体算入画。无关隐藏位置/持物/外观、异地现实身体、完整形态键、来源映射及书签不展示，不用画外条目或负向清单兜底。内部B/C不能因对外省略而丢失或提前提交。

**输出括号层级**：段落标题由连续两行组成，第一行为`【段落{编号}】`，第二行为`【总时长：{秒数}秒】`。提交标记为`【段落结束｜{编号}】`；段内字段及镜头标题用半角方括号，如`[核心要素]`、`[镜头1｜3秒]`。原文及实体名称的括号不全局替换。历史格式不因模板升级而自动返工或重复计时。

**【段内分隔】**

- 顺序为段落标题 → [核心要素] → [视频视觉风格] → 适用的[人物首次出场位置锁定]和[人物末次出场位置锁定] → 各镜头 → 段落结束标记。核心要素依次写角色、场景、道具、适用的音频实体和光影，直接换行，光影放最后。
- 段落标题的两行直接相连。段落标题后、其他实际存在的块之间及相邻镜头之间，使用独立一行`---`，上下各空一行。省略不适用的锁定或其他块时，同时省略对应分隔。
- 同段相邻两镜之间，在前一镜[音效]后、镜间`---`前写[转场]。直接切换写`[转场]：硬切。`。需要模型生成的过渡按[影视规则](cinematic-rules.md)【视频生成转场边界】写本镜实际过程及后一镜如何接上。末镜[音效]直接接`【段落结束｜{编号}】`。
- 复制整版提示词时，段间用32字符长线`━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━`，上下各空一行。逐段复制只含完整段首至段末，末尾不带段间长线。

**【成品前问题报告与复核】**：真实缺项、冲突、未决版本、无法保真匹配的声画及其他依赖，在成品前按总入口授权及[关联同步规则](../../short-drama-storyboard/references/change-sync.md)处理。确需用户决定时列出受影响的段落、现有事实和推荐做法；只暂停依赖部分。时长选择按分镜交付准入在投喂框外完成，不混入提示词；无实际问题不加例行检查报告。同一既有复核按core-rules.md【实体身份与名称统一】逐字核对完整资产引用名，同时核对：总入口按【全流程自主委托】或逐项授权交接的本范围所需缺失资产，是否已由所属模块完整编写、检查并登记采用；实际分段和镜头正文完成后的最终计次、应附送的新条目及位置图与本版资产 HTML 的实际交付是否相符，单次通常不发、必要配套按统一交付规则附送、已有不重发。名称足够引用不冒充用户已提供，合格单次不外发不冒充未完成；未完成的已授权资产也不因能引用名称而从任务中删除。不得提前估算次数或另开例行检查报告；真实问题按本段处理，镜头表达与组合以最终正文按cinematic-rules.md【整段镜头节奏检查】核验；结果复用按[分镜入口](../SKILL.md)【检查结果复用】执行。

## 内部正式制作记录（不交付用户）

按段维护以下事实，提交、中断和修订按conversation-state.md：
- **内部A计划**：本批L及其选择来源/适用范围、计划N段、墙钟估时、净发声与独占停顿、声画承载、场景有效版本、实体绑定、必要空间与摄影方案、合法形态过渡及节奏检查结果。未知不补造，不保存或展示内部推理过程。
- **内部B关系**：实际需要保存的状态交接、线程离开/恢复、连续长镜接缝及声音接续，人物位置字段读取Workflow §3输出条件及已成立的连续关系，不另建重复检查流程。按Workflow §3的归档唯一性确定记录在离开段或恢复段；完整保存所需真实位置、隐藏持物、动作/声音阶段、世界时间及合法因果。旧屏幕区位不是世界位置。
- **内部C热状态**：按线程键和时间锚隔离完整稳定形态、实际过渡、持物、门窗/连接/载具、照明运行状态、按9-B已采用的共通摄影光影造型、按连续性规则需接续的视觉效果、未闭合线程及未完声音。一镜到底另保存规定的摄影机末态及是否结束。保持与实际交付一致，未来未知不编造。
- **内部C资产及来源**：已采用人物、场景及道具资料的来源、采用范围及有效版本、显示名到完整身份键的映射、已收到的新资料登记；带版本来源范围、下一未处理位置、未完原文及动作阶段、输入队列、修订映射与已获决定的返工范围。新场景资料影响旧交付时按[关联同步规则](../../short-drama-storyboard/references/change-sync.md)处理。已有明确改法或全流程自主授权时在范围内直接执行；需要用户决定时才询问具体受影响范围。
- **内部C计时与提交**：本段实际采用的L、本批未完/完成状态、本段时长、增减及替代旧段、提交后项目有效累计；仅计正式完成段落，不把估时说成成片实测。场景资料登记与分镜完成分开。完整段落及其结束标记已实际通过可访问文件交付后，对应记录转为正式。

这些是可恢复的制作事实记录，不是对外历史复制包；不将A/B/C、完整内部状态、来源段号、字符边界或内部状态文件链接粘贴到备注/提示词。隐藏制作侧控制不取消规划、事实记录、连续性、队列与计时责任。

## 对外交付与正文填写

**【统一交付接口】**：每个时长版分别交付视频提示词 HTML 和该版适用的独立资产 HTML。资产包含实际应发的人设、场景、道具以及符合条件的人物位置图。分镜只定义视频正文并交接位置图的实际用图镜号，交付封装及资产筛选按[可编辑 HTML 交付](../../short-drama-storyboard/references/delivery.md#可编辑-html-交付)。

**【资产采用与外发分离】**：读取用户有效资料，或由对应独立资产Skill在明确授权范围内完整编写、检查并登记采用的成稿。本模块不生成资产；合格单次成稿未外发也可支持对应正式镜头，不要求先把条目发给用户。保存来源、版本、采用范围与“已采用、未交付”状态，未完成或有真实依赖问题的草稿不具备该资格。以后满足多次或必要配套附送条件且未对外发送时，按统一交付规则首次发出相应完整条目。资料登记、采用及分镜提交分开，视频书签与计时只由实际交付的完整段落推进。

每段是独立视频生成单元，段内各镜共享本段已写明的核心要素及连续声画上下文，逐镜只写该镜实际可见、发生和发声的内容；不因换镜重复已发声内容，也不把每镜另当零上下文单元。每段独立完整，不因Skill精简省必要约束或字段，不写“同上/延续上一段”，不加入内部校验、接缝来源、书签、XML、迁移清单或后期任务。视频风格由[视频视觉风格Skill](../../video-visual-style/SKILL.md)确定，本模块仅在每段专属[视频视觉风格]块中完整写入，不在其他视频字段散写风格词。分次续发的 HTML 各自完整可打开，沿用同批版别、书签和原编号。待交资产或位置图按[异常中断恢复](conversation-state.md)处理。

### 核心要素与风格

- **角色**。列本段任一镜实际可见的独立人物及背景人群，局部也算；人物与群体身份、人数说明按铁律5，引用铁律1的基础名及必要资产版本，不将应区分的版本简写为裸名。同段多个资产版本按先后用“完整版本名→完整版本名”连接，不用顿号列成多个人物。无需独立人设资产的临时状态按规则写入镜头。已采用的独立资产版本仍使用完整版本名，不由标注新增换装或变身。固定外观不复述；背景人群使用稳定群体名并注明“人群，人数或规模”，如乘凉村民（人群，共5人），说明不改变名称或资产版本。纯主观视角所有者不因有视角入栏；频次标记统一按core-rules.md【核心要素频次标记】，多次完整引用项用【】、单次不标记；整段没有人物实际入画时才写“无”。
- **场景**。列全部实际出镜场景，完整引用名按铁律1逐字沿用。按铁律2处理已知昼夜、其他场景外观版本及镜头动作或局部过程。同段涉及多个必要版本分别完整列出并用于对应镜头；未知项不猜、不写占位词。资料中的有效名与引用一致，共用参考图不合并地点身份，出场分组标记不并入名称。段落级频次标记按core-rules.md【核心要素频次标记】，多次场景完整引用项用【】、单次不标记；镜头场景栏不加频次标记。
- **道具**。按本段任一镜本体或局部实际可见的普通道具确定引用。关联组图按1-A【关联道具组图引用】列完整组图名称及必要版本，同组同版一次；其余列对应资产名。名称、实际成员与组图的映射及频次标记按core-rules.md铁律1、1-A和【核心要素频次标记】执行。全遮或隔衣摸而本体未显露不算入画，但当前必要的持有、佩戴、遮挡关系必须写对应镜头。固定场景资产按场景事实处理；无则“无”。
- **音频实体**。列本段不以视觉角色入画的语言声源及必要声音身份，非人物语言声源写稳定名称、明确音色和所需声音性别，具体声音采用按cinematic-rules.md【非人物语言声源的音色】，标注位置按【声音设定标注位置】，所需音色与声音性别只在本栏对应条目写；不附隐藏服装外观。人物既入画又发声只列角色；非语言音效写音效栏，本栏频次按core-rules.md【音频实体计次】独立统计，多次完整引用项用【】、单次不标记；无适用语言声源则省略整栏。
- **光影**。按core-rules.md 9-B写本段已确定或在该权限内设计的共通可见光影结果。同段各场景或照明条件不同时分别标明适用范围。只在特定镜头成立的摄影光影及镜内短时变化写在对应[镜头提示词]。无可写的段级光影则省略本栏。
- **视频视觉风格**。按[视频视觉风格模块](../../video-visual-style/SKILL.md)写入本版选用的完整风格及全部固定底层约束，放在本段唯一对应块。

### 位置锁定

- 依据[人物跨段位置接续](position-continuity.md)逐人、逐方向判断，有适用人物才输出对应字段`[人物首次出场位置锁定]：`或`[人物末次出场位置锁定]：`。下一行写实际采用的场景名及版本，末尾用全角冒号。确有多个剧情线程时按采用稿已有语义分组，内部线程键不进入提示词。
- 每人使用`人物名（镜头N）：场景位置：……；画面位置：……。`。首次锁定写承接前段且本段实际出镜的人物。末次锁定写需供后段继承的人物实际末次出镜结束位置。场景位置取有效固定参照物，多人关系和必要朝向按主定义，画面位置取实际对应镜头的构图。姿态在镜头表达。

### 镜头填写

- 镜号每段从1开始。[场景]使用实际采用的完整场景引用名。已知时段与状态按铁律2表达，连续跨空间按已登记连接及实际顺序用“→”。
- **摄影与取景**。明确景别、被摄对象/可见部位的基本视角、固定/运动及必要合焦变化；实际取景与可见内容按core-rules.md铁律8-C【取景范围与画面内容匹配】核对，摄影运动按cinematic-rules.md【摄影运动的可执行表达】落实；镜内光影和效果的可见过程及段内多镜接续按【按剧情选用摄影、光影与镜内效果】落实。
- **人物位置**。人物位置信息按position-continuity.md与cinematic-rules.md【人物画面构图位置】处理：已在本段首次或末次锁定记录的位置不重复；仅补两个锁定均未覆盖、且剧本明确或镜头表达必需的位置。人物实际动作、姿态、移动过程及必要起点/结果仍写清，不把位置去重当作删动作。
- **观察视点**。是否采用主观镜头及其逐镜署名按8-B；纯物件、文字或环境展示不机械添加观察者视角。删除多余视角标注时，保留剧情需要的声音，并写清发声者及发声方式。
- **可见实体**。实体名与核心要素对应，关联道具组图按1-A明确实际成员归属和动作，成员状态分别保持；镜头正文与镜头场景栏不加核心要素的频次标记。逐镜交代可见角色、旁观者、局部、物件、动作、神情及8-C规定的已确定必要持有、佩戴、接触、遮挡、放置和变化关系，不只列名或只留在人物锁定/内部。
- **临时状态**。人物临时状态及其变化按[人物临时状态取舍](shot-continuity.md)判断，需要表现的才写入对应镜头。不凭标注新增穿戴动作；人物固定外观不重复描述，必要版本名、动作和衣物遮挡关系按铁律1及8-C写清。
- **动作阶段**。动作过程与已有状态按8-C区分，保留已确定施动者、对象、参与部位及变化，不以笼统持有状态替代明确动作，不重演已完成动作或跳过未完阶段，检查全部同类表达。
- **明确事实**。原剧本明确事实按3-B保留，其余位置输出按铁律8，不在镜头正文补写超出其例外的真实场景站位、精确距离或摄影机真实坐标；人物画面构图位置按上述主定义输出；局部不补全身，必要关系不使全遮道具变为入画，不写异地现实身体或无关隐藏状态。
- **直接画面**。不写抽象不可见心理或来源信息，不为它们新增特效，也不输出“(转场)”或“（转场）”标签。
- **发声范围**。只写本镜实际发声的原台词片段及必要发声主体/方式/情绪，全部实际发声片段按顺序拼接须逐字保留完整原台词，不因换镜重复已发声内容；完整短句无必要不拆开，旁白与心声先后清楚；声画内容、先后和自然演绎时长双向匹配，不拖声等画或拖画等声。
- **语流**。先依cinematic-rules.md安排完整语流，再配画面切点；同句跨镜不额外停顿、重起或重复，不先将5秒填满再另设镜承载尾词。
- **对白跨镜**。反应镜可接原说话者的画外对白，写清原主体及方式，不要求反应人物对口型；拆句仅在引号外加[台词接续]；纯声音不要求视觉主体或口型。
- **连续长镜**。仅在[连续长镜摄影状态分工](shot-continuity.md)的限定例外中输出摄影机真实位置、方向或路径等必要接续信息，包括满足主定义的后到正文所形成的既有生成边界。普通镜头继续按原有真实空间表达边界；人物画面构图位置按文字锁定和镜头分工表达。
- **声音标注**。音色与声音性别仅写本段核心[音频实体]对应条目，此处保留发声主体、方式、内容及必要表演情绪，不重复声音设定。
- **时间与音效**。每镜[音效]写实际来源和音效，无则写“无”。常规每镜最长5秒，连续景别变化同样适用。长镜例外、单段整数总时长及容量按准入主定义，符合不中断连续长镜例外的各生成段各只有一个不中断镜头，生成边界本身不等于切镜。

### 完整短示例

该段有两个镜头，无需人物位置锁定。

```text
【段落001】
【总时长：8秒】
```
