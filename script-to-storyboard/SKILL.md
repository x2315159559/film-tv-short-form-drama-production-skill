# 短剧视频分镜

## 适用范围

将剧本与有效登记的【权威场景设定】转为可独立投喂视频模型的分镜提示词。可直接调用本Skill，并加载本目录参考文件及下列包内统一交付文件，在能够读取这些文本和用户资料的AI中执行；不需运行总入口，不依赖历史聊天、专属工具或固定电脑路径。输入类型尚未确定时，按[输入路由](../short-drama-storyboard/references/input-routing.md)的类型确认关口处理。同一已登记类型的输入续作时沿用原判断。本入口、分镜交付准入、下列七份工作流参考文件及[统一交付规则](../short-drama-storyboard/references/delivery.md)共同构成执行所需规则；以现行正文执行，冲突按 core-rules.md 的 Rule Priority 裁决。不依赖旧版技能、其他聊天或未提供的外部项目文件，也不从版本号推断规则。

本模块及参考中的“原文/原剧本/原台词”指本次已确定采用的剧本版本；由文本模块转换而来时，以用户实际采用或明确自主授权确定的右栏为输入。声音保留、来源定位与连续性均绑定该版本，不反向恢复文本阶段获准改动的小说旧句，本模块不因此获得故事改编权，表演与摄影落实权限按core-rules.md铁律3。本次全流程的文本先行与豁免、已处理采用范围的沿用，按[总入口](../short-drama-storyboard/SKILL.md)【全流程剧本处理】执行；普通阶段续作和未完恢复不重复处理同一采用稿。

- 用户只要求解释、检查或修改 Skill 时，处理该请求，不启动分镜制作或索取剧本。
- 按[输出规则](references/output-format.md)及其统一交付接口交付完整分镜。读取有效资料或明确授权下经独立资产Skill完整编写、检查并登记采用的成稿，采用和外发分别记录；本模块不生成或改写人物、场景、道具设定，视频风格由[独立视频视觉风格模块](../video-visual-style/SKILL.md)确定并完整写入各段专属块；本模块可按位置主定义编写位置图提示词，但不生成图像或视频。
- 不重新审改用户定稿；按[分镜交付准入](references/admission.md)沿用已核对表达，本模块按铁律3落实表演、摄影、具体时长、拆镜、逐镜可见性与连续性。已获分镜授权时，先按分镜交付准入【本次时长选择】取得本批上限；必要资料就绪、核验通过后直接制作，不例行再索取制作批准。
- 本模块完成后返回可核实的完成范围、剩余范围及内部来源书签，由统一入口及输入路由衔接下一阶段，不固定要求再发剧本或回复“继续”。

## 读取顺序与规则定位

按实际交付内容取用[视频 HTML 模板](assets/video.html)与[资产 HTML 模板](../short-drama-storyboard/assets/assets.html)；网页行为和独立导出见[统一交付](../short-drama-storyboard/references/delivery.md#可编辑-html-交付)。

**完整制作与续接按下列阶段读取七份参考文件，开始相关工作前应已完整读取并掌握其当前规则，不能只看入口、模板或跳读主定义。** 同上下文已完整读取且未变、仍适用的规则可复用，不机械重读；局部解释、检查或修改只读取相关主定义及依赖。

| 顺序/文件 | 主定义 |
| --- | --- |
| 1. [core-rules.md](references/core-rules.md) | Role、Objective、权威场景定义/异常裁决、全部铁律及主定义索引（含1-A、3-A/3-B、8-A至8-C、9-A至9-C）、Rule Priority。 |
| 2. [conversation-state.md](references/conversation-state.md) | 规则定位、有效历史、待处理范围、输入队列、带版本书签、剧本修订迁移、项目交付计时及恢复。 |
| 3. [cinematic-rules.md](references/cinematic-rules.md) | Workflow §3：影视规则独立板块，集中维护镜头编排、景别/视角/运镜、切镜、节奏、估时与声画承载，含按需读取的[镜头语言选择参考](references/cinematic-language-reference.md)；8-A/8-B主定义。 |
| 4. [planning-assets.md](references/planning-assets.md) | Workflow §1—§2：时长装箱、批次容量、线程键/时间锚、场景连接、资产与实体清算。 |
| 5. [shot-continuity.md](references/shot-continuity.md) | Workflow §3：场景连接、实际状态接续及【连续长镜摄影状态分工】主定义。 |
| 6. [position-continuity.md](references/position-continuity.md) | 人物在场登记、实际跨段接续需要、文字位置锁定、场景参照物与多人相对位置、独立位置图及分段标注版本。 |
| 7. [output-format.md](references/output-format.md) | 内部制作侧A/B/C、资产交付及完整提示词模板、逐段提交、批次结束。 |

先按顺序1—2核对资料库、权威版本、待处理队列及有效历史，并按 conversation-state.md【规则定位】【内部正式状态与对外交付分离】核实项目与正式进度：新项目从空制作状态开始；明确续做旧项目仅凭本次提供、可读取的有效资料恢复；本对话有可读历史则沿最后正式书签续接，不要求重发。只有明确全项目重置才清空；局部资产变更按3-A，剧本修订按2-B迁移，不套旧字符偏移。

按主定义处理实际场景资料问题后，再按顺序3—7推进本批N段规划、全部内部A/B/C与正式提示词。成品前完成下列核验；实际缺项、冲突或未决事实先具体报告，**只暂停依赖它们的部分**。相关阶段所需规则未完整读取时先补读。

**【检查结果复用】**：保留必要检查与复核。已核实、仍适用于当前版本/范围且依据未变，无失败或对应未决问题的结果直接复用；只重查变化或实际问题影响的部分。依据须实际可读，不假定跨对话/AI共享结果，不另索完整聊天或制式证明。文本表达的沿用范围按分镜交付准入执行。

与视频制作相关的新内容，按[视频视觉风格模块](../video-visual-style/SKILL.md)确定本次风格；每段专属风格块完整写入采用结果，风格描述不进入其他视频字段。涉及任何采用内容或规则变更时，按[内容变更与关联同步](../short-drama-storyboard/references/change-sync.md)处理实际影响；独立调用也只使用本次可读取的相关资料及授权，不假定共享历史。

## 必要执行提醒

- **资产资料与缺项**：按core-rules.md核实人物、场景、道具身份、采用范围和覆盖版本，可靠匹配用户设定名并复用。真实缺项列明对象、所缺版本和用途，由用户提供，或由总入口在明确授权范围内调用独立资产Skill生成；全流程授权按[总入口](../short-drama-storyboard/SKILL.md)【全流程自主委托】执行，已有授权不重复索取，本模块不自动补设。人物名称足以确定身份与版本时不强求完整外观或图片，但名称足够引用不等于用户已提供资产，也不取消已授权的缺失资产生成任务；场景需有当前摄影必需固定事实。按既有检查核对已授权资产完成及应附送条目，实际成稿后统计次数，交付按output-format.md及其统一交付接口。
- **忠实与估时**：核对原台词，使用与文本模块共用的[自然演绎估时](../short-drama-storyboard/references/performance-timing.md)，依已落实表达及[影视规则](references/cinematic-rules.md)【有效发声与超时台词】安排具体时长；旁白与心声的占比在文本改编时检查，分镜以采用稿安排实际发声，不为占比重审或改写剧本。常规单镜不超过5秒，长镜例外来源、例外单镜与整段的本批L上限统一按分镜交付准入【本次时长选择】执行。原剧本明确的位置、动作关系与道具外观按3-B落实到对应镜头；动作过程与已有状态按8-C区分，从实际阶段接续，不重演已完成动作或跳过未完动作，整批检查全部同类表达。
- **逐镜可见性**：按1、1-A、8-C及 Workflow §2【视觉出镜同步铁律】核验实际入画实体、必要关系、场景名/状态与角色状态变化。每镜正文交代可见局部、旁观者及必要持有/佩戴/接触/遮挡/放置关系，不只列名字或留在人物锁定。必要衣物遮挡须说明，但全遮物本体不算入画道具；局部不补全身，不强加未入画者。独立人物及背景人群均按铁律5列入[角色]，群体注明人群属性与人数规模；需要独立识别的个体使用稳定名称或代号。人群的位置锁定与参考图同样按[position-continuity.md](references/position-continuity.md)的条件和镜号处理，姿态及动作在镜头表达。完整身份、无关隐藏状态、来源映射及带版本书签仅内部保存。
- **视角与位置分工**：按铁律8、8-A至8-C及 Workflow §3核验真实空间位置边界与逐镜人物画面构图位置、过肩关系、基本拍摄视角所指的主体及必要可见部位。是否选用主观镜头及其归属按8-B；普通对象展示不机械加入观察者，真正主观镜头逐镜署名。镜头编排、景别、运镜、合焦对象/变化及节奏核验按[影视规则](references/cinematic-rules.md)主定义。符合分镜交付准入【本次时长选择】长镜例外、且明确要求一镜到底时均保存制作侧摄影末态，投喂区的摄影机真实空间信息仅按Workflow §3【连续长镜摄影状态分工】的限定例外写入，不另行放开人物真实场景位置、道具或固定布局的位置输出；人物画面构图位置遵守文字锁定与镜头分工，不再逐镜强制重复。
- **人物位置接续与姿态分工**：完整主定义读取[position-continuity.md](references/position-continuity.md)。依据有效在场记录，分别判断本段实际出镜人物承接前段、供后段继承位置的需要，有需要才输出对应方向文字锁定与位置图；不以出现次数触发，不把实际首次/末次出镜等同于整段首镜/末镜。文字记录真实位置及对应镜头画面构图，不记录姿态；位置图只保留准确定位必需的基础姿态及支撑关系，实际表演与变化在镜头。模板、共用条件及用图版本按同一主定义，不影响内部连续性保存。
- **提交与交付**：队列、书签及项目有效估时按conversation-state.md，内部A/B/C完整保存。视频与资产按适用时长版分别交付可编辑 HTML，正文按output-format.md。实际交付的段落正文完整且带结束标记后正式生效；不因精简省必要字段，不依赖其他对话。实际问题另行说明，未知运行状态按9-A省略，光影造型、接续及输出按9-B和影视规则执行。
