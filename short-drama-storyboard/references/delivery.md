# 交付与资产交接

本文件集中定义整套Skill的项目成品交付格式、联合任务资产附送、内部采用及自主任务剧本随附。各子Skill定义自身正文格式及生成条件。

提示词、资产、规则及其他采用内容修改后的影响复核与关联同步，统一按[内容变更与关联同步](change-sync.md)执行；本文件维护其中的交付范围与版本状态。

## 可编辑 HTML 交付

剧本使用[剧本模板](../../text-to-script/assets/script.html)，视频分段使用[视频模板](../../script-to-storyboard/assets/video.html)，人设、场景、道具及人物位置图使用同一[资产模板](../assets/assets.html)。复制对应模板，用实际项目标题及本次全部条目替换示例数据，不交付示例或空栏目。模板是可离线打开的完整 HTML；交付成品不需要样式、脚本或平台服务另行配合。

填充模板的 `delivery-data` 数据区：`title` 是本文件标题；`items` 中每条的 `text` 保留可复制的完整正文（含原字段、标题与分隔）；剧本每节另填只读 `original`；资产另填 `category`（人设／场景／道具／人物位置图），位置图填 `group`（单段位置图／跨段共用图），新设或补交的人设、场景、道具版本另按下文【资产图名】填 `imageNames`；参考关系等其他框外说明放 `note`。随分镜交付多次资产时设置 `grouped: true`，单独委托资产照原要求。以标准 JSON 序列化写入数据，将字符串内的小于号转义为 `\u003c`，避免原文被解释成网页标签；示例数据和网页控件不可混入正文。

视频条目标题从当前正文中的段号与总时长读取；资产条目标题从当前正文的条目名读取；纯外观片段等省略条目标题时，使用本条完整图名定位。编辑、撤销、重做或重新打开后，标题、定位结果及复制内容都以同一份当前正文为准。视频可按段号跳转，资产可按条目名或完整图名定位，长页可一键返回顶部。导航不改正文也不进入复制内容。

独立导出任一上述模块时，随包提供相应完整规则、所需共享规则及实际可用的 HTML 模板；文本 AI 只读取一个文件时，合订文本附相同的模板源码。模板与共用网页操作从同一套维护源生成，发布时核对各模块所附副本。全文版在最前面按模块列出各规则文件的定位目录，规则正文仍沿用既有次序。

**【可编辑 HTML 交付】**适用于本套Skill交付的剧本、视频提示词、独立视频视觉风格和资产正文。项目成品使用实际可打开、可编辑的 HTML，交付可访问的文件或链接。规则包自带的文件夹版、纯文本导出版照其发布方式管理。紧邻交付的说明、待决事项及界面控件与供复制的正文分开。规则内的代码框用于展示正文格式。

- **编辑与保存**：对外交付的可改正文可直接编辑，页面右侧有竖向滚动条，顶部提供可见、可点击的「撤销」「重做」「保存」。撤销和重做按实际编辑顺序工作，保存下载包含全部当前编辑的完整 HTML，重新打开后仍可编辑，保持内容区、格式和操作功能。复制按钮读取按下时的最新正文，保留字段、段号、镜号、分隔及空行；复制范围不包含按钮、导航、内部记录或正文外的说明。
- **剧本**：一份 HTML 内按同一叙事单元逐节展示“原版／改后版本”双栏，左栏完整保留原文，右栏可编辑。两栏随页面一起滚动；页面顶部提供「复制全部改后版本」，各节标题行右侧提供「复制本节」，整稿共用一套编辑与保存控件。采用稿的正文、审阅与版本处理仍按[剧本交付规则](../../text-to-script/references/output-and-state.md)执行。
- **视频提示词**：每个实际交付的容量版各自使用视频 HTML，提供复制全部视频提示词的按钮及每段的复制按钮。文件正文使用对应版实际分镜的段落格式、必要字段和分隔线；中断分次交付按分镜书签和交付状态续做，每次发出的 HTML 本身完整可用。
- **资产**：人设、场景、道具、人物位置图合称资产。随分镜交付时，每个容量版的应交内容合为与本版视频 HTML 配套的独立资产 HTML，依人设、场景、道具、人物位置图呈现实际有内容的类别。页顶「复制全部资产」按顺序复制四类可用正文，保留原有条目分隔、位置图分组和版本引用。各类提供复制该类全部正文的按钮及每条的复制按钮。人设、场景和道具按下文选择及分组。位置图按【独立位置图交付接口】独立列在资产 HTML 末尾。只有位置图符合交付条件时也提供资产 HTML。整版无应交资产时省略资产 HTML。单独委托的资产任务按实际范围交同样可编辑的资产 HTML。
- **独立视频视觉风格**：直接交付已选定的风格正文，支持编辑、复制及本节规定的共用操作；用于分镜时在每段内完整写入，无需额外生成风格文件。

双版交付示例：`15秒版视频提示词.html` 配 `15秒版资产.html`，`30秒版视频提示词.html` 配 `30秒版资产.html`。若同时交付两版共用的采用剧本，并列一份 `剧本.html`；文件和链接标明实际归属与范围。

项目成品无需另附 TXT 或其他重复载体。当前环境确实不能生成或交付可用 HTML 时，如实说明具体缺失的能力和未交范围；能完成的正文照常整理，未满足的交付功能不记为完成。

## 资产图名

交付人设、场景、道具时，每个实际要制作的新图或新版本，在生图提示词框上方单独显示一行“图名：完整正式名称”。使用普通文字，名称不带文件扩展名、外层条目编号或频次标记；正式名称自带的编号、括号和版本文字原样保留。采用已有参考图时，以其去掉扩展名的完整文件名为准；已有文字设定按其对应版本正式名。新设版本由所属模块确定完整名称，分镜逐字引用。现有组图及场景阶段的版本对应关系按所属模块的命名规则处理。

资产 HTML 的 `imageNames` 为字符串数组，只填完整名称。单条多版本按正文中版本的对应顺序逐一填写，图名本身须能区分版本；条目仍按原规则归组。只补外观片段时也在框外保留所属人物或道具的完整图名及版本。单个图名可独立选取、编辑及保存；单条、分类与全资产的提示词复制只读取正文。沿用已有资产不触发重发。人物位置图继续使用该类既有标题和用图版本规则。

## 内部采用与对外交付

资料登记、内部成稿、审查采用、对外交付分别记录。保存实际可读取的完整正文、来源与生成授权、基础名、版本、必要事实、检查结果、采用范围和交付状态，不以存档冒称用户已收到。

用户提供或确认的资料按有效范围读取。明确授权生成的完整资产成稿，经所属模块检查、必要事实已确定且无待决冲突后，可作为本次分镜规划和正式制作的依据；不以“先把设定发给用户”作为采用的附加门槛。未获授权、未完成或有未决冲突的资料不能编造为有效基线；缺项按对应模块处理，只暂停依赖范围。

完整链路的生成授权和顺序读取[总入口](../SKILL.md)【全流程自主委托】【全流程剧本处理】：先处理并采用剧本，再清点三类资产身份与版本，复用有效资料，将授权内所需缺项交所属独立模块完整生成、检查后采用。正文名字或能够引用名称不等于用户已提供完整资产；用户明确已有资产并给出足够引用名时，仍按原资料引用规则处理，不索取无关完整外观。资产是否必须完成按实际制作需要判断，是否随分镜外发按下节实际统计判断；单次不外发不表示可以省去所需资产的完整成稿与内部采用。

仅在当前环境实际支持且后续可读取的载体保存资料。换对话或AI只使用当次带入的规则、资料和决定，不假定共享私有记忆；缺必要基线时点名索取。

## 自主任务处理后剧本随附

**【自主任务处理后剧本随附】**：用户将本次相关工作和决定交由AI自主处理，且同一委托包含剧本处理与视频提示词制作时，在最终交付提示词时，一并提供本次实际处理、定稿并供分镜采用的完整剧本；稿本版本与范围须和所交提示词对应。完整链路默认包含的文本处理及用户明确豁免，依[总入口](../SKILL.md)【全流程剧本处理】判断，不能因本条另行扩大文本处理范围。

剧本按【可编辑 HTML 交付】提供一份“原版／改后版本”全文对照。已经完成并交付同版对照稿时，最终重新附上实际可访问的同一 HTML 或链接即可。共用同一采用稿的15秒与30秒提示词只附一份剧本；稿本不同则明确各自对应关系。剧本和版本说明独立于视频与资产正文。

本次未委托处理剧本，或用户明确跳过文本处理时，不为附送而重新改写、复制原稿或制造“处理后剧本”；正常交付所求提示词。独立文本任务的原有剧本交付不变。本条只交付实际完成且采用的范围，未完成或未采用稿不能冒充最终稿；中断、续作和旧交付保护沿现行规则，不自动返工历史提示词。

## 随分镜交付的设定：多次触发与必要配套

1. **最终统计**：完成本次实际分段和镜头正文后，按[分镜全局规则](../../script-to-storyboard/references/core-rules.md)【实体实际出场计次】统计本批、本版最终成品。本节计次处理人设、场景和道具，15秒、30秒等备选版分别统计，不在资料预检或生成前估算次数。每轮以各版全量最终正文导出该版应发设定集合，与该版资产 HTML 中的实际条目逐项双向核对，检查遗漏、错版、多发及必要版本是否齐全；按【独立位置图交付接口】核对本版位置图及引用。不能仅过滤沿用旧候选清单。
2. **多次触发新条目**：基础实体实际用于至少两个段落，且完整设定此前未对外交付、未被用户提供或确认，才在本版资产 HTML 中发送；整体/局部场景配套与关联道具组按下文的配套交付条件执行。本次新成稿与先前留存到本批满足条件的未交付成稿同样处理。只发送本次首次需要交付的实际版本；已有版本不重发。昼夜、换装等不同版本合并基础实体统计，不另造实体。
3. **单次不发送**：只用于一个段落且不属于下述必要配套附送的角色、场景、道具设定不在资产 HTML 列名称或正文，完整成稿与采用状态内部保留。核心要素的引用及频次标记按[分镜全局规则](../../script-to-storyboard/references/core-rules.md)【实体实际出场计次】执行，当前镜头画面、声音及必要关系不省略。后续交付范围实际统计达到多次且设定尚未外发时，按当批规则首次发送。
4. **已有资料不重发**：用户提供、已确认或已完整交付的设定在资产 HTML 中省略条目及名称，核心要素与镜头正常引用。新增版本只交真正缺少且符合本条或下述配套附送条件的部分，不因补夜景重发日景。
5. **固定分组与格式**：每个容量版各自一个`[多次出场]`设定组，按多次实体及其必要配套汇总，不因配套附送而增加成员的统计次数。依人设、场景、道具放实际应发的完整条目，省略无内容的类和设定组。相邻完整设定条目之间用独立一行`---`分隔，上下各空一行；同类与跨类条目均适用，同一条目内部的多个版本不插入此分隔线。每条保持所属资产Skill原格式，组标题和分隔线只在适用范围出现。
6. **交付登记**：核对所需资产已完整检查采用、本版应发条目与实际交付彼此一致，以及适用时【自主任务处理后剧本随附】是否落实。某条设定或位置图随完整、可访问的本版资产 HTML 交给用户才登记已交付；只在内部生成的成稿、残条及尚未交付的文件保持原状态。视频段落按分镜正式提交规则独立登记，资产是否外发不代替视频提交。中断后的各版状态及补交按[分镜续接规则](../../script-to-storyboard/references/conversation-state.md)执行。

**【同轮双版新资产交付】**：同一新资产在本轮两个容量版中分别满足附送条件时，按各版实际所需版本分别完整随版列出。区分本轮之前的既往交付与本轮各版交付状态；不能因先输出一版，就将另一版应发的新资产以“已交付”为由抑制。用户提供、已确认或本轮之前已完整交付的有效设定仍按已有资料不重发；本条不改变单次不发送和必要配套条件。

**【整体与局部场景配套交付】**：整体场景与独立局部场景按各自基础身份实际计次；具体统计由分镜主定义执行，交付按已登记且本次所需的配套关系判断。配套中任一场景在本批、本版达到多次出场时，一并发送该配套中尚未交付的完整整体及局部设定，不因其他成员只用一段或仅供制图而省略；触发多次的成员已交付时，其余尚未交付的必要成员也须发送。用户已提供、已确认或已交付的有效设定不重发；不为配套扩建未需场景，不改变独立计次、单双次标记或既定条目格式，不增设分组。随分镜实际交付的局部场景若确需整体参考图，按场景Skill原规则在本版资产 HTML 对应局部条目的可复制正文之外简短写明局部场景名称与所依据的整体参考图名称。只说明实际使用的参考关系，也不因此重发已提供的整体设定。

固定资产条目与镜头运行状态分开管理；临时位置、持物、伤势等不反写固定设计。关联物件画在同一资产图，视频核心要素按[分镜全局规则](../../script-to-storyboard/references/core-rules.md)1-A【关联道具组图引用】引用完整组图名，各成员的身份及实际计次分别保留。关联资产组的每个具体版本是完整的同图交付单元。组内至少一个实际采用该组版本的成员按其自身实际段数达到多次时，发送本次所需且尚未交付的完整组版本，包括该版本内必要的配套成员。以前交付过同组其他版本时，按本次版本独立核对，采用组原有名称及版本标识。同一组本次确需附送的多个版本仍归在一个道具条目下。各成员分别计次，配套成员不另列为单次设定或增加出场次数。

## 独立位置图交付接口

位置图是本版资产 HTML 末尾的独立板块，按[位置连续性主定义](../../script-to-storyboard/references/position-continuity.md)的实际人物位置接续需要生成并对应本版实际段号和镜号，独立于人设、场景和道具的多次出场计次、附送条件和`[多次出场]`设定组。生成条件、板块内的分组、条目格式和用图版本按位置连续性主定义。资产 HTML 同时包含设定组与位置图时，复制全部资产时两部分按既定段间长横线分隔，位置图内部沿用原分隔格式。

## 单独资产任务

用户单独点名生成、修改、补交某些场景、人设、道具设定时，按该任务和【可编辑 HTML 交付】交付所求范围，不等待分镜次数，也不为其先编分镜。默认“随分镜只附送多次新设定”不否定单独点名请求；用户本次明确只要多次且实际统计可读时，按该筛选范围执行。

单独委托补人物位置图提示词时，按[人物跨段位置接续](../../script-to-storyboard/references/position-continuity.md)【单独补位置图提示词】处理，按对应容量版交付仅含本次所需位置图的资产 HTML。
