# 短剧工作总入口

本入口负责识别、确认、阶段调度与交接。六个子Skill为同级文件夹，分别维护，不把资产生成算法写入文本或分镜模块。

| 子Skill | 完整规则入口 | 职责 |
| --- | --- | --- |
| text-to-script | [文本转剧本](../text-to-script/SKILL.md) | 保留故事核心进行改编，处理表达、状态适配、前稿续接与可编辑全文对照。 |
| script-to-storyboard | [剧本转分镜](../script-to-storyboard/SKILL.md) | 根据采用稿与有效资料制作独立投喂提示词；影视规则在其cinematic-rules.md独立维护。 |
| short-drama-scene-settings | [场景设定](../short-drama-scene-settings/SKILL.md) | 生成、续作或修订纯场景设定，维护固定空间及其版本。 |
| short-drama-character-sheet | [人设设定](../short-drama-character-sheet/SKILL.md) | 根据人物或人群资料生成个人展示板或人群正面全身合图提示词，按稳定身份及资产版本组织。 |
| short-drama-prop-settings | [道具设定](../short-drama-prop-settings/SKILL.md) | 提取及生成纯色背景道具资产提示词，管理关联资产组与可分离物件。 |
| video-visual-style | [视频视觉风格](../video-visual-style/SKILL.md) | 确定视频风格并融合固定视频约束，供每段专属风格块完整使用；不接管资产风格及固定模板。 |

## 独立运行与资料边界

本入口、实际调用子Skill及其引用文件组成完整执行规则，可在新对话或能够读取这些文本和用户资料的其他AI中使用，不依赖安装目录、特定模型、工具、私有记忆、旧版本或历史聊天。能读取文件时按相对链接加载；不支持相对链接时，按随包纯文本中明确的文件标题与条款名称读取。缺少当前执行实际需要的规则时，只点名索取该文件，不用版本号或记忆补造。

跨对话共享的是用户实际带入的规则与项目资料。新项目按当次资料开始；续作读取当前采用稿、有效资产、必要进度与决定。项目专名、特殊表现、返工范围、标题及编号约定归项目资料，不写成所有作品的通用要求。示例按通用判定条件理解，不能把用户举例当作适用范围的穷举。

用户明确指令及授权优先。已确认、未变且仍适用的事实与检查结果直接复用，只重查变更影响范围。用户暂停时停止制作。用户选择逐项处理后，一次只说明并询问一个独立事项，答后再问下一项；沉默和时间经过不构成批准。输出版本与容量选择按分镜准入执行，包括明确自主委托下的双版默认；局部事项授权不扩成版本选择委托。

项目成品按[可编辑 HTML 交付](references/delivery.md#可编辑-html-交付)执行；联合任务的配套资产与内部采用读取同文件的对应条款。各子Skill维护各自正文格式及生成条件。每次修改采用内容、提示词、资产或规则后，按[内容变更与关联同步](references/change-sync.md)复核实际影响，并按本次授权处理。

**画风的适用范围**：用户为整部作品指定的画风，同时用于本次受托的人设、场景、道具与视频；只指定某类、某版本或某段时，只在所指范围采用。各模块依同一已选画风的可见特征分别撰写适合制图或视频的提示词，沿用各自固定模板与约束。用户只给可辨的自定义风格名时按名称定制，指定参考图的画风时据图撰写，明确要求逐字沿用既有风格词时按原文使用。已确定的选择只登记一次；画风指定本身不启动其他制作任务。

## 全流程自主委托

**【全流程自主委托】**：用户明确将本次全流程的工作和决定交由AI时，AI在本次任务范围和用户已明确的要求内，自主完成所有步骤和各环节决定，包括发现连带影响后的处理及同步，无须询问、请求确认或等待审批。本条统一裁决总入口、各子Skill及其参考文件中要求询问、确认或审批的步骤。用户未授予全流程自主决策权限时，按各步骤原有要求询问或确认。用户只授权某一项自行决定时，自主权限仅适用于该项。仅指定完整链路、要求“继续”或一般表示可以自行改编，不等于全流程自主委托。

记录本次授权的来源、对象、范围和持续性。用户锁定的剧情核心、事实、采用资料和其他明确要求继续适用。确因资料缺失或能力不足而无法执行时，说明具体缺口及受影响范围，并完成其余可执行部分。实际需要补齐的人设、场景和道具由所属模块在授权内完成。

场景昼夜未被采用原文或有效资料明确时，全程自主决定范围内的设计与来源登记，按[场景模块](../short-drama-scene-settings/SKILL.md)【全程自主决定下的未明昼夜】执行；已有明确时段不改。

进入视频提示词制作时，输出版本与各版容量按分镜准入【本次时长选择】确定。本项自主委托覆盖该范围且用户未指定版本时，按该主定义默认交付15秒和30秒双版。

## 全流程剧本处理

**【全流程剧本处理】**：用户新委托从本次正文一直做到最终视频提示词，或明确要求先处理剧本再分镜等完整链路时，按[输入路由](references/input-routing.md)确定正文类型，再调用文本模块处理一次；输入已经是剧本也适用，只有用户明确说本次无需再处理剧本时才跳过。新的明确全流程委托可以授权处理用户本次提交的已定稿剧本，不受旧稿“定稿后停止主动审改”的保护阻断；其改编、纠错和定稿权限仍按文本模块及本次授权执行。单独直接要求分镜的任务保持剧本直达分镜，不强制经过文本模块。

同一次全流程中，文本处理后的采用稿进入资产或分镜阶段、普通继续、中断恢复及自动续作时，按当前阶段和实际断点继续，不为同一采用稿反复回转文本重改；新增或替换正文按输入路由确定类型并处理相应范围。记录本次全流程身份、输入版本、文本已处理范围或用户豁免，区分新委托与后续继续。

完整链路按以下顺序交接：文本处理一次（或用户明确豁免）→取得已采用稿→清点所需人设、场景、道具的实体身份与版本→复用有效已有资料，并将明确生成授权范围内的缺项交所属独立资产模块补齐→完整检查并登记采用→分镜制作与位置图判断→按各版最终实际段落计次→按统一规则交付对应版的视频及应交资产。全流程自主委托已经覆盖上述所需缺项；未获该生成授权的完整链路按原规则取得必要资料或具体生成授权。完整内部资产可供分镜采用，是否外发另按[交付与资产交接](references/delivery.md)判定，不因条目未达到外发条件而跳过生成或检查。

## 调度

1. **识别请求用途**：提问、维护、确认答复、资料补充和续作不当作新正文。小说、故事、文案、剧本新输入按[输入路由](references/input-routing.md)确定类型。同一已登记类型的输入正常续作时沿用原判断。资产任务按下节独立调度；单独视频视觉风格任务按输入路由直接交其独立模块，不启动正文转换或资产生成。
2. **文本转剧本**：调用文本模块及实际需要的参考，按[可编辑 HTML 交付](references/delivery.md#可编辑-html-交付)交单份两列全文对照。完整链路先按【全流程剧本处理】执行一次；正常改编、纠错、状态适配审批、定稿和续接分别按文本主定义及本次有效授权执行，不以资产图齐全为前提。
3. **剧本转分镜**：分镜阶段已指定且采用稿就绪时，调用分镜模块。视频风格未确定时，按[视频视觉风格](../video-visual-style/SKILL.md)询问并建议，用户明确授权AI决定时自主选择；已确定且仍适用的风格不为普通续作或格式修改重问。视频风格完整写在各段独立[视频视觉风格]块。人设、场景、道具分别按上文适用范围及所属模块的固定模板执行。人物文字位置锁定与独立位置图提示词按分镜[人物跨段位置接续](../script-to-storyboard/references/position-continuity.md)执行，不生成媒体。每个新制作批次按[分镜准入](../script-to-storyboard/references/admission.md)【本次时长选择】确定输出版本及各版15秒或30秒段落容量，单镜上限与长镜例外分别按同一主定义执行；身份、资产版本与出场统计按其core-rules.md【实体身份与名称统一】【实体实际出场计次】执行。分镜只读取资料，不自行生成资产。
4. **【资产缺项询问与补齐】（缺项与复用）**：制作视频提示词前，清点本次所需的人设、场景、道具及其版本，先查实际可读取的已收资料及别名、覆盖版本与交付状态。可靠匹配的用户资产必须按其有效名称、版本及设定复用，不擅自替换、改写或重复生成。按以下分支处理：
   - **未提供资产**：尚未取得下述自主授权或相应资产生成授权时，必须明确询问：“本次所需的人设、场景、道具资产，由你提供，还是由我按对应资产Skill生成？”不能仅报告缺项后跳过处理。
   - **仅提供部分资产**：使用用户已提供的有效部分，列明缺少的具体实体或版本及用途，必须询问：“这些缺少的资产由你补充，还是由我按对应资产Skill补齐？”已明确授权生成的缺项直接执行，只询问授权尚未覆盖的部分，不重索或重造已有资产。
   - **全程自主决定**：用户明确将本次任务全程及相关决定交由AI处理时，在该授权范围内，用户未提供的所需人设、场景、道具及版本必须全部交所属独立资产模块生成、检查并登记采用；用户已提供的部分必须复用，只补齐缺项，不再询问资产由谁提供。该资产授权同样适用于只委托分镜、同时明确全程自主决定的任务，不因此扩大为剧本处理或用户资产修改授权。
   正文出现名字只说明有该实体，不能登记成用户已提供资产；名称足够确定引用或当前镜头可以编写，都不能代替上述询问或已授权缺项的完整生成。用户明确已有资产并提供足够确定身份及所需版本的引用名时，按原规则引用，不强求完整外观或图片。不能仅因未上传图片、资料简短或未采用完整设定格式，就把用户已提供的有效资产列为缺项；确需补充时，须指出当前动作或摄影实际依赖、且现有资料未覆盖的具体事实及用途，不泛索整套外观或空间布置。只处理本次实际所需的具体实体或版本，不因缺项预编无用资产；生成及检查按所属模块执行，分镜模块保持只读。固定空间与动作实际必需事实确实无法从有效资料或已授权普通设计解决时，常规任务只问该事实；全流程自主决定按本入口的缺项规则执行。收到资料或提出缺项本身不等于获得生成授权；未决缺项只暂停依赖范围。
5. **联合生成与交付**：有明确资产生成授权才调用所属模块，【全流程自主委托】已包含其范围内的所需缺项。按【全流程剧本处理】清点并补齐所需实体及版本，完整成稿经所属模块既有内部检查后登记采用，完成实际分镜才统计。各版按[交付与资产交接](references/delivery.md)提供相应的视频 HTML 及应交资产 HTML；资产正文遵循各自模块，位置图按本版实际接续需要生成。
6. **完成与回转**：未完任务从有效进度继续。获授权可执行剧本全部完成分镜、分镜成品已交付且没有其他现成待制范围时，按输入路由返回文本阶段，沿剩余已提供原文续转；没有后文按授权处理。缺项、待审、待交接、待交付资产和残段不算耗尽。用户指定范围或暂停时遵从，不自行扩大范围。

## 资产Skill的调用边界

- 场景、人设、道具只有在用户明确要求生成、续作、修改，或已明确授权该范围资产生成时，才调用对应独立模块；【全流程自主委托】就是其范围内所需缺失资产的生成授权，并允许所属模块内置风格与普通设计自主选择。用户只要分镜、提供已有资产或询问缺项，不自动取得生成权限。
- 缺资料先按【缺项与复用】的登记边界核对具体名称、版本与最低事实；已授权缺项交所属模块补齐，其余由用户提供或授权生成。仅因图片未上传不能推断人物不存在或强制生人设；用户明确已有资产且引用名足够确定身份及所需版本时可直接引用，正文名字本身不冒充已有资产。道具是否需要独立资产依任务和已知事实判断，不将所有普通道具预先生图作为分镜前提。
- 只缺某个版本时，只索取或生成该版本，不重造已有版本，基础实体身份不变。真实歧义或冲突按事实报告，不靠名字相近强行匹配。
- 单独点名资产任务直接交付所求范围，不等待视频统计，不为其预编分镜或估算次数。用户明确只要多次条目且实际分镜统计可读时，按指定范围筛选。
- 资产完成不表示剧本或分镜完成。已有后续授权则交接后恢复，不重问已给方向；无授权不自行启动其他阶段。

## 版本、交接与维护

类型确定、剧本采用、资产资料登记、资产交付和视频提交分别记录。完整但未外发的单次设定不记为已交付。自主委托的双版默认按分镜准入执行；各版续作及单版采用按分镜conversation-state.md【多版本后续采用】处理，不将15秒与30秒结果相加。自主任务处理后剧本是否随提示词交付，按[交付与资产交接](references/delivery.md)【自主任务处理后剧本随附】执行。修订保留替代关系与有效范围，不因模板更新自动返工历史；依[关联同步主定义](references/change-sync.md)复核并处理实际受影响的成果。

每项制作规则只保留一个完整主定义，其余文件准确引用；示例、模板、调用路径和纯文本版与主定义一致。每次修改规则后核对流程闭环、冲突、职责和可执行性，涉及连带影响按[关联同步主定义](references/change-sync.md)处理。项目素材、历史聊天、私有路径及内部推理不作为规则包前置。
